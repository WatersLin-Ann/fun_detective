# 案件数据使用说明

本目录（`cases/`）下的所有 JSON 文件为 Fun Detective 项目的结构化案件数据。

## 许可证

本目录下的所有案件数据采用 **Creative Commons Attribution-ShareAlike 4.0 International (CC BY-SA 4.0)** 许可证。

这意味着你可以：
- ✅ 共享 — 在任何媒介以任何形式复制、发行这些数据
- ✅ 修改 —  remix、转换、基于这些数据进行创作

但必须遵守以下条件：
- 📌 **署名** — 必须给出适当的署名，提供指向本许可证的链接，并注明是否做了修改
- 🔄 **相同方式共享** — 如果你基于这些数据进行创作，必须基于与原许可证相同的许可证分发你的作品

完整许可证文本：https://creativecommons.org/licenses/by-sa/4.0/legalcode

## 数据内容声明

1. **数据性质**：本目录中的数据为对推理小说、影视作品、游戏、真实案件等的**结构化分析与设计拆解**，包括剧情梗概、诡计分析、线索链设计、游戏化设计建议等，属于评论与分析性内容。

2. **不包含原文**：数据中**不包含**受版权保护作品的大段原文、完整对话或逐句剧情复述。所有描述均为概括性、分析性的内容。

3. **真实案件**：真实案件部分基于公开可查的事实信息整理，事实本身不受版权保护。如涉及具体新闻报道的原文引用，均已做概括处理。

4. **商标与名称**：数据中出现的作品名称、角色名称、游戏名称等属于其各自权利人的商标或版权，本项目仅为识别和评论目的使用，不构成对这些权利的侵犯。
