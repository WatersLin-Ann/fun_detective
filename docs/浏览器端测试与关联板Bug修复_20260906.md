## 三、Bug 详细分析与修复

### Bug 1：关联板预设关联为空（核心原因）

**文件**：`src/game/evidence-board.js` 第 9-11 行

**问题代码**：
```javascript
function loadPresetLinks() {
  return (window.GameData && window.GameData.presetLinks) || [];
}
const presetLinks = loadPresetLinks();  // 模块加载时立即缓存
```

**根因分析**：
- `presetLinks` 是 IIFE 模块加载时就初始化的**常量**
- evidence-board.js 在 play.astro 第 270 行加载
- 案件数据通过 `GameState.loadCaseData()` **异步加载**（第 283-293 行内联脚本）
- 模块加载时 `window.GameData` 尚未设置，`presetLinks` 被缓存为空数组 `[]`
- 之后 `tryLink()` 中 `presetLinks.find(...)` 永远返回 `undefined`
- 所有关联都走 `handleCustomLink()` 分支，被保存为"自定义关联"（isCorrect: false）
- `countCorrectLinks()` 永远返回 0，审判门槛 `requireRelation` 永远不满足

**调试证据**：
```
EvidenceBoard.getPresetLinks() → 0 个（空）
window.GameData.presetLinks → 5 个（正确）
```

**修复方案**：移除常量缓存，每次使用时动态读取。

```javascript
// 修复后：不再缓存，每次调用 loadPresetLinks()
function tryLink(first, second) {
  const preset = loadPresetLinks().find(p =>  // 改为动态调用
    (p.from === first.id && p.to === second.id) ||
    (p.from === second.id && p.to === first.id)
  );
  // ...
}

function getPresetLinks() {
  return loadPresetLinks();  // 改为动态调用
}
```

**修改位置**：
- 第 11 行：删除 `const presetLinks = loadPresetLinks();`
- 第 257 行：`presetLinks.find` → `loadPresetLinks().find`
- 第 411 行：`return presetLinks;` → `return loadPresetLinks();`

### Bug 2：成功关联时抛出异常

**文件**：`src/game/evidence-board.js` 第 276 行

**问题代码**：
```javascript
function handleSuccessLink(preset) {
  const playerLinks = (window.PlayerData && PlayerData.getState().evidenceLinks) || [];
  // PlayerData.getState() 不存在！
```

**根因分析**：
- `handleSuccessLink` 调用了 `PlayerData.getState()` 方法
- 但 PlayerData 模块**没有** `getState()` 方法，只有 `getEvidenceLinks()`
- 当 `tryLink` 匹配到预设关联（Bug 1 修复后），调用 `handleSuccessLink`
- 执行到第 276 行时抛出 `TypeError: PlayerData.getState is not a function`
- 异常导致：关联数据不保存、结果弹窗不显示、信心值不增加、笔记不记录
- 用户看到的现象：点击关联后"没有任何反应"

**错误堆栈**：
```
TypeError: PlayerData.getState is not a function
    at handleSuccessLink (evidence-board.js:276)
    at tryLink (evidence-board.js:264)
    at Object.selectItem (evidence-board.js:229)
```

**修复方案**：使用正确的 API `PlayerData.getEvidenceLinks()`。

```javascript
// 修复后
const playerLinks = (window.PlayerData && PlayerData.getEvidenceLinks()) || [];
```

### Bug 3：关联按钮不显示在顶栏

**文件**：`src/pages/game-design/prototype/play.astro` 第 245 行 + `src/game/gameRender.js` 第 131 行

**问题 3a：CSS 移动端 `!important` 强制隐藏**

```css
@media (max-width: 640px) {
  #relation-btn, #timeline-btn { display: none !important; }
}
```

- 测试视口 489px < 640px，触发移动端规则
- `!important` 覆盖了 JS 中 `style.display = ''` 的设置
- 关联按钮永远隐藏，用户只能从"更多"菜单进入关联板

**问题 3b：JS 没移除 Tailwind `hidden` class**

```javascript
// 按钮初始 class 含 hidden
<button id="relation-btn" class="... hidden" ...>

// JS 只设置了 style.display，没移除 hidden class
relationBtn.style.display = relationUnlocked ? '' : 'none';
```

- 按钮初始有 Tailwind 的 `hidden` class（`display: none`）
- JS 设置 `style.display = ''` 只是清除 inline style，`hidden` class 仍然生效
- 即使 CSS 的 `!important` 移除了，按钮还是因为 `hidden` class 而不显示

**修复方案**：

1. play.astro：移除 `!important` 强制隐藏，改为缩小按钮尺寸适配移动端
```css
#relation-btn, #timeline-btn { 
  padding: 0.4rem 0.5rem; 
  font-size: 0.75rem; 
  min-height: 36px; 
}
```

2. gameRender.js：同步控制 `hidden` class
```javascript
if (relationBtn) {
  relationBtn.classList.toggle('hidden', !relationUnlocked);
  relationBtn.style.display = relationUnlocked ? '' : 'none';
}
// 时间线按钮同理
```

## 六、其他发现

### 1. 按钮点击被遮挡（非 Bug，测试环境问题）

- 部分按钮（开场"继续"、场景"前往餐车"）用 ref 点击不生效
- 原因：Astro 开发工具栏（dev toolbar）或其他元素遮挡
-  workaround：用 Tab+Enter 键盘操作，或坐标点击
- 不影响实际用户游玩（用户直接用鼠标点击不受影响）

### 2. `__exit` 场景切换逻辑

- `__exit` 函数中，`GameState.state.currentScene = sceneId` 在 if 块外面
- 即使显示了审判确认对话框，也会立即切换场景
- 不影响功能（确认后会重新渲染为审判阶段），但逻辑上可以优化
