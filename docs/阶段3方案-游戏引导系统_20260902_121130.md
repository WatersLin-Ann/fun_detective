## 一、系统目标

### 核心价值
1. **降低上手门槛**：新玩家首次进入游戏时，通过引导快速了解操作方式
2. **减少卡关**：玩家不知道下一步该做什么时，提供目标提示
3. **增强沉浸感**：引导以"侦探助手"的形式出现，不破坏游戏氛围
4. **可跳过**：老玩家可以快速跳过引导

### 设计原则
- **不剧透**：引导只提示操作方式，不透露案件内容
- **可关闭**：玩家可以随时关闭引导
- **上下文感知**：根据当前游戏阶段提供不同引导
- **首次触发**：只在首次进入时显示，后续可手动开启

## 二、功能模块

### 2.1 新手教程（首次进入）

#### 触发条件
- 玩家首次进入游戏（localStorage中无教程完成标记）
- 或玩家手动点击"帮助"按钮

#### 教程内容
1. **欢迎界面**：介绍游戏背景和目标
2. **操作引导**：
   - 如何切换场景
   - 如何收集证据
   - 如何询问证人
   - 如何使用笔记
   - 如何进入审判
3. **目标提示**：当前阶段的目标

#### 展示方式
- 分步引导弹窗（每步一个提示）
- 高亮当前需要点击的区域
- "下一步"和"跳过"按钮

### 2.2 任务目标系统

#### 目标类型
| 阶段 | 目标 | 完成条件 |
|------|------|----------|
| 调查阶段 | 收集证据 | 收集X件证据 |
| 调查阶段 | 询问证人 | 询问X个证人 |
| 调查阶段 | 整理线索 | 打开笔记查看 |
| 调查阶段 | 发现矛盾 | 发现X个矛盾 |
| 审判阶段 | 质询证人 | 质询所有证人 |
| 审判阶段 | 出示证据 | 出示X次证据 |
| 审判阶段 | 最终选择 | 做出最终选择 |

#### 展示方式
- 顶部栏显示当前目标（简洁文字）
- 点击目标展开详细说明
- 目标完成后自动切换到下一个

### 2.3 进度引导（下一步提示）

#### 触发条件
- 玩家在某个阶段停留超过一定时间（如60秒无操作）
- 或玩家点击"提示"按钮

#### 引导内容
- 根据当前进度，提示下一步该做什么
- 例如："你已经收集了2件证据，还有3件证据在其他场景"
- 例如："你还没有询问列车员，去问问他吧"

#### 展示方式
- Toast提示（不打断游戏）
- 或"侦探助手"对话框

## 三、数据结构

### 3.1 玩家状态扩展

```javascript
state.tutorialCompleted = false;  // 教程是否完成
state.currentObjective = null;    // 当前目标ID
state.completedObjectives = [];   // 已完成的目标ID
state.hintCooldown = 0;           // 提示冷却时间
```

### 3.2 案件目标配置

在案件数据中添加`objectives`字段：

```javascript
objectives: [
  {
    id: 'obj-001',
    phase: 'investigation',  // investigation / trial
    title: '收集现场证据',
    description: '在案发现场收集所有可用的证据',
    type: 'collect_evidence',
    target: 5,  // 需要收集的数量
    hint: '点击场景中的物品来收集证据'
  }
]
```

## 五、风险和注意事项

### 风险1：引导过于烦人
- **问题**：频繁的提示会打断游戏体验
- **解决**：引导可关闭，有冷却时间，只在必要时显示

### 风险2：引导剧透
- **问题**：提示可能透露案件内容
- **解决**：引导只提示操作方式，不透露具体内容

### 风险3：目标系统复杂
- **问题**：目标判断逻辑可能复杂
- **解决**：基础版本只做简单的数量统计目标

### 注意事项
- 教程只在首次进入时显示
- 老玩家可以跳过
- 引导可以随时在设置中重新开启
- 目标完成要有明确的反馈
