## 一、重构背景

### 重构前问题
1. 审判流程简单：只是"选证人→看证词→出示证据"的循环
2. 无异议系统：缺乏逆转裁判风格的"异议！"触发机制
3. 证人无情绪反应：被指出矛盾时证人没有变化
4. 信心值不影响结局：最终结局只看选择，不看信心值
5. 缺乏审判节奏：没有开场、质询、总结陈词的阶段划分

---

## 二、重构内容

### 1. 多阶段审判流程

#### 审判阶段划分
```
审判开场（opening）
  ↓ 点击"开始质询"
证人质询（questioning）
  ↓ 询问所有证人后
总结陈词（closing）
  ↓ 点击"进入最终选择"
最终选择（verdict）
  ↓
结局评价（根据信心值评级）
```

#### 新增状态字段
```javascript
state.trialPhase = 'opening';  // opening | questioning | closing | verdict
state.currentWitnessIndex = 0;
state.witnessStates = {  // 每个证人的质询状态
  [witnessId]: {
    questioned: false,     // 是否已询问
    followedUp: false,     // 是否已追问
    contradicted: false,   // 是否已被指出矛盾
    emotion: 'normal'      // 当前情绪
  }
};
state.objectionActive = false;  // 异议动画是否激活
```

---

### 2. 异议系统（Objection System）

#### 触发时机
- 证人陈述证词时，如果该证人有未被发现的矛盾，显示"⚡ 异议！"按钮
- 点击后播放异议动画（大字"异议！"从屏幕弹出，红色闪烁）
- 1.5秒后自动打开证据选择面板
- 选择证据后检查是否正确指出矛盾

#### 视觉效果
- 全屏黑色遮罩（80%透明度）
- 大号红色"异议！"文字，带发光效果和弹跳动画
- 倾斜-5度，增加视觉冲击力

#### 实现位置
- gameRender.js：异议动画遮罩HTML + CSS
- gameInteractions.js：`window.__object()` 函数处理异议逻辑

---

### 3. 证人情绪系统

#### 五种情绪状态
| 情绪 | 表情 | 触发条件 | 文字颜色 |
|------|------|----------|----------|
| normal | 平静 | 初始状态 | 灰色 |
| confident | 自信 | 开始陈述时 | 蓝色 |
| nervous | 紧张 | 被追问时 | 黄色 |
| angry | 愤怒 | 被错误指责时 | 红色 |
| breakdown | 崩溃 | 被正确指出矛盾时 | 紫色 |

#### 视觉表现
- 火柴人表情变化（使用stickFigureWithExpr）
- 证词文字颜色随情绪变化
- 证人卡片上显示情绪标签
- 被指出矛盾的证人卡片有红色边框标记

#### 状态追踪
每个证人的状态记录在`state.witnessStates[witnessId]`中：
- questioned：是否已询问
- followedUp：是否已追问
- contradicted：是否已被指出矛盾
- emotion：当前情绪

---

### 4. 信心值影响结局

#### 五级评级系统
| 信心值 | 评级 | 评价文案 | 颜色 |
|--------|------|----------|------|
| 90-100 | S级 | 完美推理！你洞察了一切真相 | 金色 |
| 70-89 | A级 | 出色的推理，几乎没有遗漏 | 绿色 |
| 50-69 | B级 | 不错的推理，但还有一些疑点 | 蓝色 |
| 30-49 | C级 | 推理不够充分，真相仍有迷雾 | 黄色 |
| 0-29 | D级 | 推理失败，真凶逍遥法外 | 红色 |

#### 实现
- 在renderEnding中根据信心值计算评级
- 结局页面顶部显示大号评级字母和评价文案
- 评级显示在`#ending-grade`元素中

---

### 5. 审判节奏控制

#### 审判开场（opening）
- 大法官图标 + "审判开始"标题
- 法官对话框说明案件背景
- 提示玩家质询方法
- "开始质询 →"按钮进入下一阶段

#### 证人质询（questioning）
- 顶部显示进度：已质询人数、矛盾数、信心值
- 进度条显示质询进度
- 证人卡片显示状态（已问/追问/矛盾/情绪）
- 所有证人询问完后显示"进入总结陈词"按钮

#### 总结陈词（closing）
- 波洛整理所有发现的矛盾
- 列出已发现的矛盾列表
- 显示最终信心值
- "进入最终选择 →"按钮

## 五、已知限制和待优化

### 1. 异议动画较简单
- 当前只有文字弹跳，没有复杂的动画效果
- **优化方向**：后续可添加滑动、震动、粒子效果

### 2. 证人情绪触发点较少
- 当前只有：询问→自信、追问→紧张、正确矛盾→崩溃、错误→愤怒
- **优化方向**：可增加更多触发点（如连续追问、特定证词等）

### 3. 总结陈词内容较简单
- 当前只列出矛盾点，没有波洛的推理过程
- **优化方向**：可添加更丰富的推理叙事
