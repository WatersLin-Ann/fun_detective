## 任务 0.1：建立稳定的组件 ID / data-tour 标识规范

### 问题
教程锚点指向不存在的 ID（`#scene-tabs`、`#witness-list`、`#evidence-bar`、`#trial-btn`），导致教程高亮失效。

### 修改内容

| 文件 | 修改 |
|------|------|
| `play.astro` | 为 6 个顶栏/舞台元素添加 `data-tour` 属性和稳定 ID |
| `gameRender.js` | `renderInvestigation` 中用 `<div id="scene-interactables" data-tour="interactables">` 包裹所有场景热点 |
| `ui.js` | 对话框 `#game-dialog-box` 添加 `data-tour="dialog"` |
| `guideUI.js` | 教程步骤 `highlight` 字段改为 `target`，统一使用 data-tour ID；新增 `getTourElement()` 存在性校验；渲染时 `scrollIntoView` 定位 |

### data-tour 元素清单（共 8 个）

| data-tour ID | 元素 | 位置 |
|-------------|------|------|
| `evidence` | 证据按钮 `#evidence-btn` | play.astro 顶栏 |
| `relation` | 关联按钮 `#relation-btn`（默认隐藏，解锁后显示） | play.astro 顶栏 |
| `timeline` | 时间线按钮 `#timeline-btn`（默认隐藏，解锁后显示） | play.astro 顶栏 |
| `more` | 更多/帮助按钮 `#more-btn` | play.astro 顶栏 |
| `notebook` | 笔记按钮 `#notebook-btn` | play.astro 顶栏 |
| `stage` | 游戏舞台 `#game-scene-container` | play.astro 调查区 |
| `interactables` | 场景热点容器 `#scene-interactables` | gameRender.js 动态渲染 |
| `dialog` | 对话框 `#game-dialog-box` | ui.js 动态创建 |

### 教程步骤更新
- 旧步骤引用 `#scene-tabs`、`#evidence-bar`、`#witness-list`、`#trial-btn`（均不存在）
- 新步骤引用 `stage`、`interactables`、`evidence`、`notebook`、`more`（全部存在）
- 新增 `getTourElement(target)` 函数：不存在时 `console.warn` 并跳过，不阻塞教程流程

### 验收结果
- ✅ `document.querySelectorAll('[data-tour]')` 返回 8 个元素（≥6 要求）
- ✅ 教程每个步骤的 target 均能在 DOM 中找到
- ✅ 所有 data-tour 元素为 `<button>` 或可聚焦容器，键盘 Tab 可达
- ✅ 顶栏按钮补充了 `aria-label`（证据栏、线索关联板、案件时间线、帮助与更多选项、推理笔记）

## 任务 0.2：建立游戏专用 CSS Token

### 问题
游戏壳颜色硬编码在 Tailwind 类中（`bg-stone-800`、`text-amber-600` 等），无法按案件切换主题色，也无法统一管理。

### 修改内容

**play.astro 新增 `<style is:global>` 块**，定义 13 个游戏 Token：

| Token | 值 | 用途 |
|-------|-----|------|
| `--game-bg` | `#0d0d12` | 游戏壳近黑底色 |
| `--game-surface` | `#1a1a24` | 卡片/面板表面 |
| `--game-surface-hover` | `#252532` | hover 状态 |
| `--game-border` | `#2e2e3e` | 边框 |
| `--game-text` | `#e8e8f0` | 主文本 |
| `--game-text-muted` | `#8888a0` | 次要文本 |
| `--game-accent` | `#f59e0b` | 默认琥珀色强调色 |
| `--game-accent-soft` | `rgba(245,158,11,0.15)` | 强调色半透明背景 |
| `--game-danger` | `#ef4444` | 危险/错误 |
| `--game-success` | `#22c55e` | 成功 |
| `--game-info` | `#3b82f6` | 信息 |
| `--game-radius` | `12px` | 统一圆角 |
| `--game-focus-ring` | `0 0 0 3px rgba(245,158,11,0.5)` | 键盘焦点环 |

**案件主题色覆盖**（由 `data-case` 属性驱动）：

| 案件 | data-case 值 | accent 色 |
|------|-------------|-----------|
| 东方快车 | `orient-express` | `#f59e0b`（琥珀） |
| 血字的研究 | `study-in-scarlet` | `#dc2626`（血红） |
| 逆转裁判 | `phoenix-wright-1` | `#3b82f6`（法庭蓝） |

**gameRender.js `updateTopBar`** 中新增：
```javascript
const caseId = window.GameData?.meta?.id;
if (caseId) {
  document.documentElement.setAttribute('data-case', caseId);
}
```

**额外新增**：
- `.game-button:focus-visible` 全局焦点样式（使用 `--game-focus-ring`）
- `.game-button` 基础类（cursor + transition）
- `@keyframes hotspot-pulse` 热点脉冲动画（供阶段 2 使用）
- `.hotspot-highlight` 可调查物高亮类（供阶段 2 使用）

### 验收结果
- ✅ `:root` 下定义了 13 个游戏 Token（≥12 要求）
- ✅ 三案件有独立的 `--game-accent` 和 `--game-focus-ring` 覆盖
- ✅ 切换案件时 `document.documentElement.dataset.case` 跟随变化，强调色联动
- ✅ Token 体系已建立，后续阶段可逐步替换硬编码颜色
