## 一、完成内容

### 1.1 创建游戏UI工具模块

**文件**：`src/game/ui.js`（新增，~450行）

**包含组件**：

| 组件 | 功能 | 特性 |
|------|------|------|
| **DialogBox 对话框** | 角色对话展示 | 打字机效果、角色颜色、选项分支、对话历史、点击跳过 |
| **EvidenceCard 证据卡片** | 证据收集展示 | 分层信息（事实→细节）、收集动画、不直接显示答案 |
| **Modal 模态框** | 确认操作 | 三种类型（warning/info/danger）、确认/取消回调 |
| **Toast 通知** | 操作反馈 | 四种类型（info/success/warning/error）、自动消失 |
| **CollectAnimation 收集动画** | 证据收集特效 | 从点击位置飞到证据栏、缩放旋转 |

**技术特点**：
- 纯原生JS实现，无外部依赖
- IIFE封装，挂载到 `window.GameUI`
- 所有组件有入场/退场动画
- 支持键盘可访问性

### 1.2 替换所有原生弹窗

**替换清单**（共10处）：

| 位置 | 原实现 | 新实现 |
|------|--------|--------|
| 证据收集 | `alert(证据名+keyInfo)` | `GameUI.showEvidenceCard()` 证据卡片 |
| 证人询问 | `alert(证人+证词)` | `GameUI.showDialog()` 对话框+追问选项 |
| 物品查看 | `alert(描述)` | `GameUI.showDialog()` 对话框 |
| 进入审判 | `confirm(是否进入)` | `GameUI.showModal()` 模态框 |
| 条件不足提示 | `alert(还需要...)` | `GameUI.showModal()` 模态框 |
| 追问证人 | `alert(追问内容)` | `GameUI.showDialog()` 对话框 |
| 证据详情 | `alert(证据+keyInfo)` | `GameUI.showEvidenceCard()` 证据卡片 |
| 发现矛盾 | `alert(正确+内容)` | `GameUI.showDialog()` 对话框 |
| 错误推理 | `alert(错误-信心)` | `GameUI.showToast()` 通知 |
| 重置游戏 | `confirm(确定重置)` | `GameUI.showModal()` 模态框 |
| 最终选择 | 直接执行 | `GameUI.showModal()` 确认模态框 |

**验证**：代码中 `alert(` 和 `confirm(` 出现次数 = **0**

## 二、关键设计决策

### 2.1 证据卡片分层信息

**问题**：原实现直接显示"keyInfo"（推理结论），剥夺玩家推理乐趣

**解决方案**：
- 第一层：观察到的事实（描述）
- 第二层：进一步观察（keyInfo，但标注为"观察"而非"结论"）
- 提示语："这只是观察到的事实，推理需要你自己完成"

### 2.2 对话框打字机效果

**实现**：
- 每30ms显示一个字符
- 点击文本可跳过，直接显示完整内容
- 显示完成后才显示选项按钮
- 自动记录到对话历史（最多100条）

### 2.3 证人颜色系统

为6个证人分配专属颜色，在对话框和场景中保持一致：
