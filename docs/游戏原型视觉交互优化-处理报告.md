## 一、问题背景

用户反馈"游戏方面没有做优化"，经排查发现根本原因：

> 游戏主页面（play.astro）通过 **JS动态渲染** 场景和对话框，使用内联HTML模板字符串，**未使用** GameScene/DialogBox 组件。因此之前对组件的修改完全没有生效。

**截图证据**：游戏场景仍显示圆形emoji头像（👤），无场景装饰元素。

### 优化1：场景背景适配

**修改文件**：`src/pages/game-design/prototype/play.astro`  
**修改位置**：`renderInvestigation()` 函数

**实现方式**：
- 新增 `sceneBgs` 配置对象，定义6种场景类型的渐变背景
- 新增 `sceneDecor` 场景装饰HTML生成逻辑
- 根据 `scene.sceneType` 自动选择背景和装饰

**场景类型与效果**：

| 场景类型 | 背景渐变 | 装饰元素 |
|----------|----------|----------|
| train（列车） | 深蓝夜色 | 两侧车窗、地板阴影 |
| corridor（走廊） | 深灰透视 | 两侧门、地板阴影 |
| room（房间） | 灰色调 | 墙壁纹理、门框、地板 |
| dining（餐车） | 暖棕色调 | 餐桌、吊灯、灯光 |
| outdoor（户外） | 蓝天绿地 | （预留） |
| office（办公室） | 蓝灰调 | （预留） |

**代码示例**：
```javascript
const sceneBgs = {
  train: 'linear-gradient(180deg, #1a1a2e 0%, #16213e 50%, #0f3460 100%)',
  corridor: 'linear-gradient(180deg, #1a1a1a 0%, #2a2a2a 50%, #333 100%)',
  // ...

const bgGradient = scene.sceneType ? sceneBgs[scene.sceneType] : scene.background;
```

### 优化4：角色表情动态变化

**实现方式**：
- state 新增 `witnessReaction` 字段，记录当前证人情绪
- 支持6种表情：normal / happy / sad / angry / surprised / thinking
- 新增 `setWitnessReaction(reaction)` 辅助函数，2秒后自动恢复normal
- 火柴人SVG根据表情切换眼睛和嘴巴形状

**表情映射表**：

| 表情 | 眼睛 | 嘴巴 | 触发场景 |
|------|------|------|----------|
| normal | ● ● | — | 默认状态 |
| happy | ◠ ◠ | ◡ | （预留） |
| sad | ◡ ◡ | ◠ | （预留） |
| angry | > < | ︵ | 出示证据发现矛盾 |
| surprised | ○ ○ | ○ | （预留） |
| thinking | ● - | ~ | 追问后 |

**情绪状态标签**：对话框显示"情绪：平静/激动/思考/惊讶"

### 优化5：场景切换动画

**修改位置**：`renderInvestigation()` 函数开头

**实现方式**：
- state 新增 `isTransitioning` 标志，防止动画叠加
- 切换场景时：容器 opacity 0 → translateY(10px)
- 50ms后：opacity 1 → translateY(0)
- CSS transition：0.3s ease 缓动

**代码示例**：
```javascript
const sceneContainer = document.getElementById('game-scene-container');
if (sceneContainer && !state.isTransitioning) {
  state.isTransitioning = true;
  sceneContainer.style.opacity = '0';
  sceneContainer.style.transform = 'translateY(10px)';
  sceneContainer.style.transition = 'opacity 0.3s ease, transform 0.3s ease';
  setTimeout(() => {
    sceneContainer.style.opacity = '1';
    sceneContainer.style.transform = 'translateY(0)';
    state.isTransitioning = false;
  }, 50);
}
```

### 优化6：对话历史功能

**实现方式**：
- state 新增 `dialogueHistory` 数组，存储对话记录
- 每条记录包含：speaker（说话人）、text（内容）、color（颜色）、time（时间戳）
- 最多保留50条，自动清理旧记录
- 新增 `addDialogueHistory(speaker, text, color)` 辅助函数
- 新增 `__toggleTrialHistory()` 全局函数，切换历史面板显示
- 历史面板显示最近8条，每条截断60字符

**历史记录数据结构**：
```javascript
{
  speaker: '赫伯德夫人',
  text: '我听到了奇怪的声音...',
  color: '#ec4899',
  time: 1693401600000
}
```
