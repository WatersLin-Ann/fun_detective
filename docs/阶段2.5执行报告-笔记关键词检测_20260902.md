## 一、系统概述

### 核心功能
玩家在笔记中写下特定关键词，可以解锁隐藏的对话内容、线索或增加信心值。这鼓励玩家主动思考和记录推理，而不是被动收集证据。

### 设计理念
- 玩家在笔记的"线索"、"推理"、"待验证"三栏中输入内容
- 系统自动检测输入内容是否包含预设关键词或别名
- 检测到关键词后，解锁隐藏内容并给予反馈
- 已解锁的关键词在笔记UI中展示

## 二、数据结构

### 2.1 关键词配置

在案件数据文件中添加`noteKeywords`字段：

```javascript
noteKeywords: [
  {
    id: 'kw-oe-001',
    keyword: '12人',
    aliases: ['十二人', '12乘客'],
    category: '推理',
    unlockType: 'dialog',  // dialog / confidence
    description: '12人与陪审团的联系',
    unlockContent: {
      speaker: '波洛',
      text: '隐藏推理内容...',
      confidence: 10
    }
  }
]
```

## 三、功能实现

### 3.1 关键词检测

#### 检测时机
- 玩家在笔记任意一栏添加内容时触发检测
- 检测函数：`checkKeywords(text)`

#### 检测逻辑
1. 获取案件的所有关键词配置
2. 遍历每个关键词，检查是否已发现
3. 对未发现的关键词，检测文本是否包含关键词或别名
4. 匹配方式：不区分大小写的包含匹配
5. 匹配成功后标记为已发现，触发解锁反馈

#### 解锁类型
| 类型 | 说明 | 反馈 |
|------|------|------|
| dialog | 解锁隐藏对话 | 弹出对话框显示推理内容 + 增加信心值 |
| confidence | 增加信心值 | Toast提示 + 信心值增加 |

### 3.2 解锁反馈

- **对话框**：显示角色的隐藏推理内容
- **Toast提示**："发现关键词「XXX」！"
- **音效**：播放收集音效
- **信心值**：增加5-15点
- **笔记记录**：关键词标记为已解锁

### 3.3 笔记UI集成

#### 已解锁关键词区域
- 位于笔记弹窗底部
- 显示已解锁数量/总数（如 3/8）
- 已解锁关键词显示：关键词 + 描述
- 未解锁时显示提示文案

## 七、已知限制和待优化

### 1. 关键词数量较少
- 东方快车8个，血字的研究6个
- **优化方向**：后续案件可增加更多关键词

### 2. 解锁内容较简单
- 当前主要是对话框和信心值
- **优化方向**：可解锁隐藏证据、隐藏证人、特殊剧情分支

### 3. 无输入提示
- 玩家不知道有哪些关键词
- **优化方向**：可添加微妙的提示系统（不剧透）

### 4. 关键词检测仅在添加时触发
- 修改已有笔记内容不会触发检测
- **优化方向**：可在保存时也检测一次
