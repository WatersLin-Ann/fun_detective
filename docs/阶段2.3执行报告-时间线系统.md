## 一、系统概述

### 核心功能
时间线系统为推理游戏增加了新的维度：玩家需要收集事件发生的时间线索，整理时间线，发现时间上的矛盾。

### 与现有系统的关系
- **证据关联系统**：证据↔证人的关联
- **时间线系统**：事件↔时间的关联，发现时间冲突
- **笔记系统**：时间线线索自动记录到笔记
- **审判系统**：时间线矛盾增加信心值

## 二、数据结构

### 2.1 时间线事件

每个案件数据中添加`timeline`字段：

```javascript
timeline: [
  {
    id: 'tl-oe-001',
    time: '22:00',           // 时间点
    title: '列车发车',        // 事件标题
    description: '...',       // 详细描述
    source: '场景',           // 来源类型：场景/证据/证人
    sourceId: 'intro',       // 来源ID
    category: '行程'          // 分类：行程/证词/物证/推测
  }
]
```

### 2.2 时间线矛盾

```javascript
timelineContradictions: [
  {
    id: 'tc-oe-001',
    event1: 'tl-oe-003',     // 事件1 ID
    event2: 'tl-oe-002',     // 事件2 ID
    description: '...',      // 矛盾描述
    confidence: 15           // 发现后增加的信心值
  }
]
```

### 2.3 玩家状态

```javascript
state.discoveredTimeline = [];  // 已发现的时间线事件ID
state.timelineContradictionsFound = [];  // 已发现的时间线矛盾ID
```

## 三、功能实现

### 3.1 时间线索收集

#### 收集方式（自动）
1. **场景进入**：切换到新场景时，自动收集该场景的时间线索
2. **证据收集**：收集证据时，自动收集该证据的时间线索
3. **证人询问**：询问证人时，自动收集该证人的时间线索

#### 收集反馈
- Toast提示："发现时间线索：XX:XX 事件名称"
- 播放收集音效
- 自动记录到笔记的线索栏

### 3.2 时间线UI

#### 弹窗布局
- 顶部：标题 + 已发现数量 + 矛盾数量 + "检测矛盾"按钮
- 主体：垂直时间线，按时间排序
  - 已发现事件：时间点（琥珀色）+ 分类标签 + 标题 + 描述 + 来源
  - 未发现事件：显示"??:?? 未发现的时间线索"（半透明，不剧透）
- 底部：已发现的时间线矛盾列表

#### 视觉设计
- 时间线竖线（左侧）
- 彩色圆点标记分类（蓝色=行程，绿色=证词，琥珀色=物证，紫色=推测）
- 卡片式事件展示
- 可滚动区域（最大高度60vh）

### 3.3 矛盾检测

#### 检测逻辑
- 玩家点击"检测矛盾"按钮
- 系统检查已发现的事件中是否有预设的矛盾组合
- 两个事件都已发现 → 揭示矛盾
- 矛盾揭示后：
  - 显示矛盾详情
  - 增加信心值（+10~15）
  - 记录到笔记的推理栏
  - 播放成功音效

## 七、已知限制和待优化

### 1. 时间线矛盾未在审判中使用
- 当前时间线矛盾只增加信心值，未在审判阶段作为证据出示
- **优化方向**：审判阶段可以出示时间线矛盾

### 2. 收集方式较简单
- 当前只有自动收集（场景/证据/证人）
- **优化方向**：可添加手动推理收集（关联两个事件解锁新时间线）

### 3. 时间线事件数量较少
- 东方快车8个，血字的研究6个
- **优化方向**：后续案件可增加更多时间线事件

### 4. 时间线UI较基础
- 当前是简单的垂直列表
- **优化方向**：可添加横向时间轴、缩放、筛选等功能
