## OE-P0-01：存档恢复无限选择循环

**问题描述**：有存档的玩家点击「继续游戏」后，再次弹出「发现存档」选择框，无法进入游戏。

**根因分析**：
- `gameState.js` 的 `continueSavedGame()` 使用 `state = JSON.parse(saved)` 重新赋值内部 `state` 变量
- 但 `GameState` 对象导出的 `state` 属性是模块加载时的旧引用
- 渲染层 `GameRender.render()` 读取 `GameState.state.pendingSaveChoice`，拿到的仍是旧对象（`true`）
- 因此每次渲染都判定需要显示存档选择框，形成无限循环

**修复方案**：
- 改用 `Object.assign(state, savedData)` 将存档数据合并到现有 state 对象
- 不替换对象引用，确保外部持有的 `GameState.state` 能看到更新后的值
- 同步修复 `init()` 中 `continue=1` 分支的同样问题
- 添加 try-catch 防御存档解析失败

**修改文件**：`src/game/gameState.js`
- 第 226-231 行：`init()` 中 `state = JSON.parse(...)` → `Object.assign(state, ...)`
- 第 296-308 行：`continueSavedGame()` 中同样改为 `Object.assign`

**验证**：语法检查通过，冒烟测试同步检查通过。

## OE-P0-03：异议遮罩永不收起

**问题描述**：审判中点击「异议！」后，全屏黑色遮罩显示，但 1.5 秒动画结束后遮罩不消失，玩家无法继续操作。

**根因分析**：
- `gameInteractions.js` 的 `__object()` 在 1.5 秒后正确设置 `objectionActive=false` 并调用 `GameRender.render()`
- 但 `gameRender.js` 的 `renderTrial()` 中只有：
  ```javascript
  if (st.objectionActive) {
    overlay.classList.remove('hidden');
  }
  ```
- 缺少 `else` 分支在状态为 false 时加回 `hidden`
- `#objection-overlay` 是全屏 `z-[100]` 黑色遮罩，一旦显示就永远留在屏幕上

**修复方案**：
- 添加双向同步逻辑，`objectionActive` 为 false 时显式加回 `hidden`
- 提取变量避免重复 getElementById

**修改文件**：`src/game/gameRender.js`（第 393-402 行）

```javascript
// 修复前
if (st.objectionActive) {
  const overlay = document.getElementById('objection-overlay');
  if (overlay) overlay.classList.remove('hidden');
}

// 修复后
const objectionOverlay = document.getElementById('objection-overlay');
if (objectionOverlay) {
  if (st.objectionActive) {
    objectionOverlay.classList.remove('hidden');
  } else {
    objectionOverlay.classList.add('hidden');
  }
}
```

**验证**：语法检查通过。

## OE-P0-04：关联结果弹窗内容为空 + 叠层反转

**问题描述**：
1. 成功关联后弹出的结果框只显示标题「发现关键关联！」，正文为空
2. 1.5 秒后证据板自动重开，与结果弹窗同为 `z-[95]`，后插入的证据板盖住结果框，玩家可能无法点击「继续推理」

**根因分析**：

**问题 A — 内容为空**：
- `evidence-board.js` 的 `showResultModal()` 调用 `GameUI.showModal({ content: ... })`
- 但 `ui.js` 的 `showModal()` 只解构 `message` 字段，渲染 `escapeHtml(message)`
- `content` 字段被完全忽略，`message` 默认为空字符串
- 即使传 `message`，`escapeHtml()` 也会转义 HTML 标签，无法渲染富文本

**问题 B — 叠层反转**：
- `handleSuccessLink()` 在显示结果框后，固定 1.5 秒执行 `closeBoard(); openBoard()`
- 重开的证据板 DOM 后插入，与结果弹窗同为 `z-[95]`
- 后插入的元素在同 z-index 下覆盖先插入的，结果框被盖住

**修复方案**：

**A. showModal 支持富文本**：
- 新增 `content` 参数（富文本，不转义），优先于 `message`（纯文本，转义）
- 渲染时：`content ? <div>${content}</div> : <p>${escapeHtml(message)}</p>`
- 新增 `hideCancel` 参数，关联结果弹窗只显示「继续推理」一个按钮

**B. 移除固定延时重开**：
- 删除 `setTimeout(() => { closeBoard(); openBoard(); }, 1500)`
- 改为将刷新逻辑作为 `onConfirm` 回调传入结果弹窗
- 玩家点击「继续推理」后才关闭结果框并刷新证据板
- 确保同一时刻只有一个顶层 modal

**C. showResultModal 参数适配**：
- 第三个参数在 success/already 时为回调函数，fail 时为 first 对象
- 函数内部根据 type 区分处理

**修改文件**：
- `src/game/ui.js`：`showModal()` 支持 `content` 和 `hideCancel`
- `src/game/evidence-board.js`：`showResultModal()` 签名重构，`handleSuccessLink()` 移除延时重开

**验证**：语法检查通过，冒烟测试通过。

## OE-P1-08：结局复玩按钮报错

**问题描述**：通关后点击「再玩一次」，结局浮层隐藏但游戏无响应，控制台抛出 `GameState.reset is not a function`。

**根因分析**：
- `endingUI.js` 的 `replay()` 调用 `GameState.reset()`
- 但 `gameState.js` 只导出了 `resetSavedGame()`，没有 `reset()` 方法
- 按钮先隐藏结局浮层，再调用不存在的方法抛出异常，后续 `init()` 和 `render()` 不执行
- 玩家只能手动刷新页面

**修复方案**：
- 改用已存在且语义完整的 `GameState.resetSavedGame()`
- 该方法会：清除 localStorage 存档 → 重置 state 各字段 → 设置 `pendingSaveChoice=false` → 调用 `GameRender.render()` 回到开场
- 清理证据栏残留状态（`showEvidenceBar`、`evidenceMode`、`selectedEvidence`）
- 添加兜底：如果 `resetSavedGame` 不存在则 `window.location.reload()`
- 移除冗余的 `GameState.init()` 和 `GameRender.render()` 调用（resetSavedGame 内部已处理）

**修改文件**：`src/game/endingUI.js`（第 196-213 行）

**验证**：语法检查通过。
