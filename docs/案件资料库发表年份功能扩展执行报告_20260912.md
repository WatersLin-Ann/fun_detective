## 六、已知限制与后续建议

### 已知限制
1. **年代筛选不同步到 URL**：当前年代筛选仅在客户端生效，刷新页面后会重置为「全部年代」。后续可将 `year` 参数加入 URL 同步。
2. **无年份案件排序**：发表时间排序时，无年份的案件 year=0，会排在旧→新的最前面或新→旧的最后面。
3. **git 本地权限问题**：`.git/objects` 目录权限被拒绝，无法使用本地 git 命令，需通过 API 推送。

### 后续建议
1. **新增100个案件**：当前202个案件已全部补充发表年份，可按原计划继续新增100个完整内容的案件（推理小说30/真实案件25/影视25/游戏20）。
2. **年代筛选 URL 同步**：将 `year` 参数加入 `writeUrlState` 和 `readUrlState`，支持页面刷新后保留筛选状态。
3. **年份统计展示**：在 Hero 区域或筛选栏旁增加各年代案件数量统计，帮助用户快速了解数据分布。
4. **git 权限修复**：排查 `.git/objects` 权限问题，恢复本地 git 命令可用性。
