# 阶段2.4方案 - 审判机制重构

**执行时间**：2026-09-02
**任务**：阶段2.4 - 审判机制重构
**状态**：方案制定中

---

## 一、当前审判机制现状

### 现有功能
1. 证人列表展示（6个证人）
2. 选择证人查看证词
3. 追问证人获取更多信息
4. 出示证据检查矛盾（正确+20信心，错误-10）
5. 矛盾点进度显示（X/4）
6. 找到3个以上矛盾可进入最终选择

### 存在问题
1. **流程简单**：只是"选证人→看证词→出示证据"的循环，缺乏审判的紧张感
2. **无异议系统**：没有逆转裁判风格的"异议！"触发机制
3. **证人无情绪反应**：被指出矛盾时证人没有变化
4. **信心值不影响结局**：最终结局只看选择，不看信心值
5. **缺乏审判节奏**：没有开场、质询、总结陈词的阶段划分

---

## 二、重构目标

### 核心增强
1. **异议系统**：证词中出现矛盾时，玩家可以点击"异议！"触发反驳
2. **多轮质询流程**：审判开场→逐个证人质询→总结陈词→最终判决
3. **证人情绪系统**：证人有normal/confident/nervous/angry/breakdown五种情绪
4. **信心值影响结局**：最终信心值决定结局评价（S/A/B/C/D级）
5. **审判节奏控制**：阶段化推进，增加沉浸感

---

## 三、详细设计

### 3.1 异议系统（Objection System）

#### 触发时机
- 证人陈述证词时，如果玩家已收集到相关证据，可以点击"异议！"按钮
- 异议后进入证据选择界面，选择证据反驳证词
- 正确：证人情绪变化+信心值上升+解锁新信息
- 错误：信心值下降+证人嘲讽

#### UI设计
- 证词区域右下角添加"异议！"按钮（红色，醒目）
- 点击后弹出证据选择面板
- 选择证据后播放异议动画（大字"异议！"从屏幕一侧滑入）

#### 实现位置
- gameRender.js：renderTrial中添加异议按钮和动画
- gameInteractions.js：添加__object()函数处理异议逻辑

---

### 3.2 多轮质询流程

#### 审判阶段划分
```
审判开场（法官说明案件）
  ↓
证人质询（逐个证人：陈述→追问→异议→反驳）
  ↓
总结陈词（波洛整理所有矛盾）
  ↓
最终选择（指出凶手/作案手法）
  ↓
结局评价（根据信心值和选择给出评级）
```

#### 状态新增
```javascript
state.trialPhase = 'opening' | 'questioning' | 'closing' | 'verdict';
state.currentWitnessIndex = 0;  // 当前质询到第几个证人
state.witnessStates = {  // 每个证人的质询状态
  [witnessId]: {
    questioned: false,     // 是否已询问
    followedUp: false,     // 是否已追问
    contradicted: false,   // 是否已被指出矛盾
    emotion: 'normal'      // 当前情绪
  }
}
```

### 3.3 证人情绪系统

#### 情绪类型
| 情绪 | 表情 | 触发条件 |
|------|------|----------|
| normal | 平静 | 初始状态 |
| confident | 自信 | 开始陈述时 |
| nervous | 紧张 | 被追问时 |
| angry | 愤怒 | 被错误指责时 |
| breakdown | 崩溃 | 被正确指出矛盾时 |

#### 视觉表现
- 火柴人表情变化（已有stickFigureWithExpr支持）
- 证词文字颜色变化（紧张时偏黄，愤怒时偏红）
- 情绪标签显示在证人头像旁

---

### 3.4 信心值影响结局

#### 结局评级
| 信心值 | 评级 | 评价文案 |
|--------|------|----------|
| 90-100 | S级 | 完美推理！你洞察了一切真相 |
| 70-89 | A级 | 出色的推理，几乎没有遗漏 |
| 50-69 | B级 | 不错的推理，但还有一些疑点 |
| 30-49 | C级 | 推理不够充分，真相仍有迷雾 |
| 0-29 | D级 | 推理失败，真凶逍遥法外 |

#### 实现
- 在renderEnding中根据信心值显示不同评级
- 结局文案根据评级动态变化

---

### 3.5 审判节奏控制

#### 审判开场
- 法官对话框："现在开始审理东方快车谋杀案..."
- 介绍案件背景和嫌疑人
- 点击"开始质询"进入证人质询

#### 总结陈词
- 所有证人质询完成后，波洛总结所有矛盾点
- 显示已发现的矛盾列表
- 点击"进入最终选择"

#### 最终判决
- 玩家选择凶手和作案手法
- 根据信心值+选择给出最终评价

## 五、风险和注意事项

### 风险1：状态兼容性
- 旧存档没有新状态字段
- **解决**：init时检查并补全默认值

### 风险2：渲染复杂度增加
- 多阶段渲染可能导致代码冗长
- **解决**：拆分为renderTrialOpening/renderTrialQuestioning/renderTrialClosing等子函数

### 风险3：异议动画影响性能
- 大字动画可能卡顿
- **解决**：使用CSS transform动画，避免重排

### 注意事项
- 保持向后兼容，旧的审判流程仍可运行
- 不改变案件数据结构（data-orient-express.js）
- 异议系统需要证据和证词的矛盾映射（已有contradictions数据）
