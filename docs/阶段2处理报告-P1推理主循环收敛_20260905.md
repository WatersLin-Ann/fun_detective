# 阶段 2 处理报告：P1 推理主循环收敛

**执行时间**: 2026-09-05
**阶段目标**: 玩家在 30 秒内能理解「收集 → 关联/矛盾 → 审判」的循环；顶栏不超过 4 个常驻操作；进入审判必须有关键推理行为。
**涉及任务**: 2.1（顶栏重构）、2.2（可调查物提示）、2.3（推进门槛）、2.4（主循环差异化）、2.5（弹层焦点管理）

## 任务 2.1：游戏专用顶栏重构

### 问题
- P1-01：顶栏 8+ 控件并列（返回、案件名、阶段、信心值、音量、证据、关联、时间线、目标、帮助、笔记、重置），信息过载
- 主站导航与游戏壳并存，沉浸感被打断
- 笔记、帮助、重置等低频操作占用常驻空间

### 修改内容

**顶栏新结构（左中右三栏）**：

| 位置 | 内容 | 说明 |
|------|------|------|
| 左侧 | `← 退出` | 带确认弹窗，返回案件列表 |
| 中央 | 案件名 + 阶段/信心值 + 当前目标 | 动态更新，truncate 防溢出 |
| 右侧 | 证据 N + 关联(条件) + 时间线(条件) + ⋯更多 | 最多 4 个按钮 |

**更多菜单（点击 ⋯ 展开）**：
- 📝 笔记
- 🔗 线索关联（解锁后显示）
- ⏱️ 案件时间线（解锁后显示）
- ❓ 帮助 / 教程重看
- 🔄 重置进度（红色，带确认）

**工具解锁规则**：
- 开场阶段：隐藏证据按钮（无证据可查）
- 收集 ≥2 条证据：关联按钮从更多菜单提升到顶栏
- 发现时间线内容：时间线按钮从更多菜单提升到顶栏
- 审判阶段：阶段指示器显示「审判 N/M 证人」

**主站导航隐藏**：
- play.astro 加载时给 body 添加 `game-page` class
- CSS `body.game-page header, body.game-page footer { display: none }`
- 游戏页背景改为 `var(--game-bg)` 深色

**其他变更**：
- 移除重复的 `loadCaseData` 初始化（gameInteractions.js 底部），统一由 play.astro 内联脚本初始化
- 所有按钮添加 `game-button` 类和 `min-height: 44px`
- 移除音频按钮（音频总开关关闭，预留到更多菜单的设置项）

### 验收结果
- ✅ 顶栏常驻操作 ≤4 个（退出 + 证据 + 关联/时间线 + 更多）
- ✅ 笔记、重置、帮助移入更多菜单，不占常驻空间
- ✅ 游戏页不显示主站 header 和 footer
- ✅ 退出和重置均有确认弹窗，不误触
- ✅ 关联/时间线按钮按条件解锁，不提前暴露
- ✅ 所有按钮 min-height 44px，符合触控标准

## 任务 2.2：调查场景可调查物提示

### 问题
- P1-02：场景热点名称仅 hover 显示，移动端无法 hover，新玩家不知道哪里可点
- 首次进入场景无引导，玩家可能错过关键证据
- 无调查进度感知

### 修改内容

**热点名称始终可见**：
- 移除 `opacity-0 group-hover:opacity-100`，改为 `opacity-100` 始终显示
- 名称标签使用 `bg-black/85` 半透明底，不遮挡场景
- 已完成的热点名称后加 ✓ 标记

**首次进入脉冲提示**：
- 模块级 `_visitedScenes` Set 追踪已访问场景
- 首次进入场景时，未完成的热点添加 `hotspot-pulse` 类
- 脉冲动画 1.5s × 2 次后自动停止（CSS keyframes）
- 再次进入同一场景不触发脉冲

**可调查物开关**：
- 场景右上角添加「👁️ 隐藏热点 / 👁️‍🗨️ 显示热点」按钮
- 状态存储在 sessionStorage（`fun-detective-hotspots-hidden`）
- 隐藏模式下热点 opacity 降至 0.25，hover 时恢复 1.0

**调查进度指示**：
- 场景标题下方显示「可调查 N/M」（已完成数/总数）
- 实时更新，收集证据或询问证人后刷新

**触控尺寸**：
- 证人热点：min-width 56px × min-height 72px
- 证据/出口热点：min-width 56px × min-height 56px
- 场景出口按钮：min-height 44px

### 验收结果
- ✅ 不 hover 也能看到所有热点名称
- ✅ 首次进入场景时未调查热点有脉冲动画
- ✅ 场景标题显示可调查进度 N/M
- ✅ 热点显示/隐藏开关可用，状态会话内保持
- ✅ 移动端触控区域 ≥44×44px

## 任务 2.3：推进门槛改为关键关联/矛盾

### 问题
- P1-03：进入审判仅检查证据数和证人数（minEvidence + minWitnesses），玩家可凑数进入
- 缺少对核心推理行为（建立关联、发现矛盾）的要求

### 修改内容

**三案 trialRequirement 扩展**：

| 案件 | minEvidence | minWitnesses | requireRelation | requireContradiction | 核心推理 |
|------|------------|-------------|-----------------|---------------------|---------|
| 东方快车 | 3 | 2 | ✅ true | ❌ false | 线索关联 |
| 血字的研究 | 3 | 2 | ❌ false | ✅ true | 发现矛盾 |
| 逆转裁判 | 0 | 0 | ❌ false | ✅ true | 法庭异议 |

**`__exit` 函数重写**：
- 构建 `missing` 数组，逐项检查所有门槛条件
- 计数门槛：证据 N/M、证人 N/M
- 关联门槛：`EvidenceBoard.countCorrectLinks() >= 1`
- 矛盾门槛：`GameState.state.contradictionsFound.length >= 1`
- 未满足时显示具体缺失项列表（每项带 hint 文案）
- 全部满足时才显示「进入审判」确认弹窗

**校验脚本更新**：
- trialRequirement 缺少主门槛条件时 warning（已全部消除）
- 校验结果：0 错误 0 警告

### 验收结果
- ✅ 东方快车必须建立至少 1 条正确关联才能进入审判
- ✅ 血字的研究必须发现至少 1 个矛盾才能进入审判
- ✅ 门槛不满足时显示具体缺失项和操作提示
- ✅ 纯凑数（只收集证据不问证人/不推理）无法进入审判
- ✅ `npm run validate:cases` 0 错误 0 警告

## 任务 2.4：三案主循环差异化配置

### 问题
- 三案使用相同的调查→审判循环，无案件特色
- 进度提示文案通用，不引导玩家关注案件核心机制

### 修改内容

**三案 mainLoop 配置**：

| 案件 | type | hint |
|------|------|------|
| 东方快车 | `relation` | 收集线索后在线索关联板中建立关联，找到关键关联后可进入审判 |
| 血字的研究 | `contradiction` | 询问证人并追问，发现证词中的矛盾，找到矛盾后可进入审判 |
| 逆转裁判 | `courtroom` | 阅读证词，追问细节，发现矛盾时点击「异议！」并出示证据反驳 |

**应用位置**：
- `guideUI.showProgressHint()`：调查阶段无当前目标时，显示 mainLoop.hint
- `gameRender.renderTrialOpening()`：审判开场提示使用 mainLoop.hint 替代通用文案

### 验收结果
- ✅ 东方快车进度提示引导玩家使用关联板
- ✅ 血字的研究进度提示引导玩家发现矛盾
- ✅ 逆转裁判审判提示引导法庭异议流程
- ✅ 三案提示文案差异化，不千篇一律

## 任务 2.5：弹层焦点管理 + aria-live 状态播报

### 问题
- P2-05：弹层无焦点管理，键盘用户 Tab 会跳出弹层到背景
- 无 Esc 关闭弹层的统一处理
- 状态变化（证据收集、目标完成）无屏幕阅读器播报

### 修改内容

**全局 Esc 键处理**（ui.js）：
- 按层级从高到低检查 7 个弹层（modal → notebook → evidence-board → timeline → tutorial → more-menu → dialog）
- 关闭最上层打开的弹层
- 只绑定一次（`_escBound` 防重复）

**焦点管理**（ui.js）：
- `openOverlay(id, focusSelector)`：保存当前焦点 → 显示弹层 → 聚焦弹层内第一个可聚焦元素
- `closeOverlay(id)`：隐藏弹层 → 恢复焦点到触发元素
- 所有弹层添加 `role="dialog"` `aria-modal="true"` `aria-label`

**aria-live 状态播报**：
- Toast 通知：`role="status" aria-live="polite"`
- 目标显示：`aria-live="polite"`（目标变化时自动播报）

**弹层覆盖清单**：

| 弹层 | role | aria-modal | aria-label | Esc关闭 |
|------|------|-----------|------------|---------|
| 教程 | ✅ | ✅ | 新手教程 | ✅ |
| 笔记 | ✅ | ✅ | 推理笔记 | ✅ |
| 关联板 | ✅ | ✅ | 线索关联板 | ✅ |
| 时间线 | ✅ | ✅ | 案件时间线 | ✅ |
| 确认弹窗 | ✅ | ✅ | 确认对话框 | ✅ |
| 对话框 | ✅ | ✅ | 对话 | ✅ |
| 更多菜单 | — | — | — | ✅ |

### 验收结果
- ✅ 打开任一弹层后按 Esc 可关闭
- ✅ 弹层打开时焦点进入弹层内第一个按钮
- ✅ 关闭弹层后焦点回到触发按钮
- ✅ 所有弹层有 role="dialog" 和 aria-modal="true"
- ✅ Toast 和目标变化有 aria-live 播报
- ✅ 多个弹层叠加时 Esc 只关闭最上层
