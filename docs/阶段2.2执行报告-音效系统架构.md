## 一、架构设计

### 核心理念
- **架构先行，内容后补**：先搭建完整的音效管理架构和触发点，后续只需替换音频文件即可
- **无依赖运行**：当前使用Web Audio API生成占位合成音，不依赖任何真实音频文件
- **配置驱动**：所有音效配置集中在audio-config.js，便于管理和替换

### 模块划分

| 模块 | 文件 | 职责 |

| 音效管理器 | `src/game/audioManager.js` | 音频播放核心，BGM/SFX/音量控制/淡入淡出 |

## 二、音效管理器（audioManager.js）

### 功能特性

#### 1. 三层音量控制
- **主音量**（master）：控制所有音频
- **BGM音量**（bgm）：独立控制背景音乐
- **SFX音量**（sfx）：独立控制音效
- 支持静音切换

#### 2. BGM管理
- 循环播放
- 场景切换自动播放
- 淡入淡出（预留接口）
- 停止/切换

#### 3. SFX管理
- 一次性音效播放
- 支持同时多个音效
- 和弦音效（多音符叠加）

#### 4. 占位合成音
使用Web Audio API生成：
- **单音**：playTone(frequency, duration, type, volume)
- **和弦**：playChord(frequencies, duration, type, volume)
- 支持波形类型：sine / square / triangle / sawtooth

#### 5. 浏览器兼容性
- 支持Web Audio API
- 处理浏览器自动播放策略（用户交互后resume）
- 降级处理（初始化失败不影响游戏）

### API接口

```javascript
AudioManager.init()                    // 初始化
AudioManager.playBgm(bgmId)            // 播放BGM
AudioManager.stopBgm()                 // 停止BGM
AudioManager.playSfx(sfxId)            // 播放音效
AudioManager.setMasterVolume(vol)      // 设置主音量
AudioManager.setBgmVolume(vol)         // 设置BGM音量
AudioManager.setSfxVolume(vol)         // 设置SFX音量
AudioManager.toggleMute()              // 切换静音
AudioManager.getVolume()               // 获取音量状态
```

## 四、游戏集成

### 1. BGM自动切换

在render()函数中，根据游戏阶段自动播放对应BGM：

```javascript
const bgmId = AudioConfig.phaseBgmMap[state.gamePhase] || 'investigation';
AudioManager.playBgm(bgmId);
```

阶段映射：
- `intro` → intro BGM
- `investigation` → investigation BGM
- `trial` → trial BGM
- `ending` → ending BGM

### 2. SFX触发点

| 事件 | 音效 | 位置 |
|------|------|------|
| 收集证据 | collect_evidence | 证据卡片确认后 |
| 证据关联成功 | link_success | EvidenceBoard.checkLink |
| 证据关联失败 | link_fail | EvidenceBoard.checkLink |
| 审判反驳正确 | trial_correct | 审判阶段出示证据 |
| 审判反驳错误 | trial_wrong | 审判阶段出示证据 |
| 音量按钮点击 | click | toggleAudio |

### 3. 音量控制UI

顶部栏添加音量控制按钮：
- 🔊：正常状态
- 🔇：静音状态
- 点击切换静音/取消静音

### 4. 初始化流程

```javascript
// 在init()中
AudioManager.init();
AudioManager.setMasterVolume(AudioConfig.settings.masterVolume);
AudioManager.setBgmVolume(AudioConfig.settings.bgmVolume);
AudioManager.setSfxVolume(AudioConfig.settings.sfxVolume);
```

## 八、已知限制和待优化

2. **BGM淡入淡出未完全实现**：预留了接口，但合成音模式下效果有限
3. **音频预加载未实现**：引入真实文件后需要考虑预加载策略
4. **部分SFX触发点未覆盖**：对话开始/继续、按钮悬停等触发点待添加
5. **音量设置未持久化**：当前音量设置不保存到localStorage，刷新后重置
