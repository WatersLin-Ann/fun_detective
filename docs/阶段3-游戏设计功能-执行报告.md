### 2.2 游戏模板详情页
- **路径**：`/fun_detective/game-design/templates/[name]`
- **文件**：`src/pages/game-design/templates/[name].astro`
- **生成页面**：5个（推理审判模板、密室逃脱模板、连环案件模板、多视角叙事模板、时间回溯模板）
- **功能**：
  - 面包屑导航
  - 模板标题、描述、核心循环可视化（4阶段流程图）
  - 快速信息：难度曲线、适合时长、适配诡计标签
  - 4个Tab切换（URL hash记录，支持深链）：
    - 阶段设计：4个阶段的详细设计（玩家目标、关键机制、设计要点）
    - 适配诡计：列出适配的诡计类型及详情
    - 参考案例：使用该模板的游戏案例卡片
    - 设计要点：通用设计建议（难度控制、信息节奏、反馈机制、复用性）
  - 上一个/下一个模板导航

  - 侧边导航（桌面端）：10种诡计快速跳转，滚动高亮
  - 平滑滚动动画

## 七、用户体验亮点

1. **一站式设计参考**：从诡计类型→游戏机制→游戏模板→参考案例，形成完整的设计参考链路
2. **深链支持**：Tab状态和诡计锚点都记录在URL中，支持分享和收藏
3. **搜索筛选**：诡计映射页支持实时搜索和多维度筛选，方便快速定位
4. **条件渲染**：无改编建议的案例不显示游戏Tab，保持页面简洁
5. **相似推荐**：基于诡计类型智能推荐相似游戏案例，帮助设计师找到参考
6. **导航整合**：全站统一入口，用户可以从任何页面快速到达游戏设计功能

## 八、已知限制与后续优化方向

### 当前限制
1. 模板详情页的"参考案例"匹配基于关键词，可能不够精准
2. 诡计映射页的搜索只支持前端过滤，数据量增大后可能需要优化
3. 游戏化改编建议目前只有10个案例，后续可扩充
4. 无用户收藏和对比功能

### 阶段4预览（可选方向）
1. **游戏关卡生成器**：输入案例→输出基于模板的关卡结构文档
2. **可玩原型**：基于某个模板，做一个简单的可交互推理游戏原型
3. **用户收藏**：用户可以收藏案例和模板，本地存储
4. **对比工具**：多选案例/模板，横向对比机制和设计
5. **模板扩充**：增加更多游戏模板（如桌游改编模板、VR推理模板等）
