## 三、补充内容标准

### 3.1 完整故事（800-1500字）

**结构**：
1. 背景介绍（案件发生的环境、人物关系铺垫）
2. 案件发生（受害者、发现过程、现场情况）
3. 调查过程（侦探介入、关键发现、转折）
4. 推理高潮（线索串联、诡计揭示）
5. 结局真相（凶手、动机、手法）

### 3.2 关键时间线（5-10个节点）

**格式**：
- 时间/阶段：事件描述
- 包括：案发前、案发时、调查中、真相揭露

### 3.3 角色档案（3-8个角色）

**每个角色包含**：
- 姓名
- 身份
- 与案件关系
- 动机
- 关键行为

### 3.4 线索链（5-15条线索）

**每条线索包含**：
- 线索编号
- 线索内容
- 线索类型（关键线索/误导线索/背景信息）
- 指向结论
- 出现时机（开篇/前期/中期/后期/终局）

## 六、注意事项

1. **内容准确性**：基于公开资料整理，不编造关键情节
2. **剧透处理**：完整故事包含剧透，在页面上已有"查看完整故事"按钮保护
3. **真实案件**：尊重受害者，不渲染暴力细节，聚焦推理和调查过程
4. **分批提交**：每批完成后提交到GitHub，避免一次性大量变更
5. **同步飞书**：本地更新后，需要同步回飞书Base（或在飞书中直接更新）
