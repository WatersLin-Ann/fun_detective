## 二、新发现问题：案件内容质量缺口

### 2.1 问题一：延伸阅读大面积缺失

**巡检结果**（2026-09-02，全量扫描202个案件）：

| 分类 | 总数 | 有参考链接 | 无参考链接 | 覆盖率 |
|------|------|-----------|-----------|--------|
| 影视 | 33 | 13 | 20 | 39% |
| 推理小说 | 83 | 37 | 46 | 44% |
| 游戏 | 39 | 19 | 20 | 48% |
| 真实案件 | 47 | 22 | 25 | 46% |
| **合计** | **202** | **91** | **111** | **45%** |

**根因分析**：

1. **数据字段可选**：`基本信息.参考链接` 在类型定义中为可选字段（`参考链接?: ReferenceLink[]`），录入时无强制校验
2. **案件量激增后未回填**：8月30日《案例内容补充方案》统计时仅116个案件、参考链接完整率90%；此后案件扩展到202个，新增的86个案件大量未录入参考链接
3. **ZOO子案件拆分未继承**：ZOO系列拆分为11个子案件（七个房间、动物园、向阳之诗等），拆分时仅父案件ZOO.json保留了参考链接，子案件全部丢失
4. **飞书同步无校验**：从飞书Base同步到本地JSON时，未对参考链接字段做非空校验或覆盖率告警

**影响**：
- 超过一半的案件详情页底部不显示"延伸阅读"模块
- 用户无法从案件页跳转到维基百科、豆瓣、IMDb等权威来源深入了解
- 降低了案件库的可信度和内容深度

### 2.2 问题二：视频推荐功能完全未实现

**巡检结果**：

- **数据模型**（`src/lib/types.ts`）：无任何视频相关字段（无 `RelatedVideo`、`视频链接`、`推荐视频` 等接口）
- **前端页面**（`src/pages/case/[...slug].astro`）：无视频推荐UI模块
- **仅有的关联**：`linkTypeIcon` 中定义了 `'B站': '📺'` 图标，仅供参考链接类型为"B站"时使用，不构成视频推荐功能

**当前案件详情页已有的推荐模块**：

| 模块 | 数据来源 | 状态 |
|------|----------|------|
| 延伸阅读 | 基本信息.参考链接 | ⚠️ 54%案件缺失 |
| 相关案例推荐 | 诡计类型/地区/难度算法匹配 | ✅ 正常 |
| 相似游戏案例参考 | 诡计类型匹配游戏类案件 | ✅ 正常（仅游戏化改编建议存在时显示） |
| 视频推荐 | — | ❌ 未开发 |

**根因分析**：

1. **从未规划**：项目想法文档和各阶段方案中均未提及视频推荐功能
2. **数据无承载**：没有对应的字段存储视频链接、标题、来源等信息
3. **前端无渲染**：案件详情页没有预留视频推荐区域

**影响**：
- 用户无法通过视频直观了解案件（如真实案件的纪录片、影视案件的预告片/解说、游戏案件的实况视频）
- 缺少多媒体内容维度，案件页以纯文字为主，沉浸感不足

## 三、解决方案

### 3.1 延伸阅读补全方案

#### 3.1.1 数据标准

每个案件的 `基本信息.参考链接` 应包含至少2条，按来源类型标注：

| 类型 | 适用案件分类 | 来源示例 |
|------|-------------|----------|
| 维基百科 | 全部 | zh.wikipedia.org / en.wikipedia.org |
| 豆瓣 | 推理小说/影视 | book.douban.com / movie.douban.com |
| IMDb | 影视 | imdb.com |
| B站 | 全部（解说/纪录片） | bilibili.com |
| Steam | 游戏 | store.steampowered.com |
| 官方网站 | 游戏/影视 | 官方站点 |
| 百度百科 | 真实案件/中国作品 | baike.baidu.com |
| 其他 | 特殊来源 | — |

每条参考链接格式：
```json
{
  "标题": "维基百科 - ZOO（小说）",
  "URL": "https://zh.wikipedia.org/wiki/ZOO_(小說)",
  "类型": "维基百科"
}
```

#### 3.1.2 补全策略

**批量自动补全 + 人工校验**：

1. **按分类自动检索**：
   - 推理小说 → 维基百科 + 豆瓣读书
   - 影视 → 维基百科 + 豆瓣电影 + IMDb
   - 游戏 → 维基百科 + Steam + 官方网站
   - 真实案件 → 维基百科 + 百度百科（中国案件）

2. **ZOO子案件特殊处理**：11个子案件继承父案件ZOO.json的参考链接（维基百科+豆瓣），因为它们是同一本短篇集的不同故事

3. **人工校验**：自动补全后，对URL有效性和标题准确性做抽样校验（至少20%抽样）

#### 3.1.3 同步机制改进

- 在飞书Base中为"参考链接"字段添加必填校验（至少1条）
- 同步脚本 `sync_from_lark.py` 添加覆盖率检查，低于80%时告警
- 数据校验脚本 `data_validator.py` 增加参考链接字段检查

### 3.2 视频推荐开发方案

#### 3.2.1 数据模型扩展

在 `types.ts` 中新增视频推荐接口：

```typescript
export interface RelatedVideo {
  标题: string;
  URL: string;
  来源: 'B站' | 'YouTube' | '其他';
  时长?: string;
  简介?: string;
  类型?: '解说' | '纪录片' | '预告片' | '实况' | '其他';
}
```

在 `BasicInfo` 中添加可选字段：
```typescript
推荐视频?: RelatedVideo[];
```

#### 3.2.2 前端渲染

在案件详情页 `[...slug].astro` 中，延伸阅读模块下方新增"相关视频推荐"模块：

- 展示位置：延伸阅读模块之后、相关案例推荐之前
- 展示形式：卡片网格，每个视频卡片含标题、来源标签、时长、简介
- 点击跳转到外部视频平台（新窗口打开）
- 无视频数据时不显示该模块

#### 3.2.3 视频内容策略

| 案件分类 | 推荐视频类型 | 数量 |
|----------|-------------|------|
| 推理小说 | 书籍解说/作者访谈 | 1-2条 |
| 影视 | 预告片/影评解说 | 1-3条 |
| 游戏 | 游戏实况/攻略/评测 | 1-3条 |
| 真实案件 | 纪录片/案件解说 | 1-2条 |

**来源优先级**：B站（国内可访问）> YouTube > 其他

## 六、风险与注意事项

1. **链接有效性**：自动检索的URL可能存在重定向或失效，批量补全后需抽样验证
2. **真实案件敏感性**：真实案件的视频推荐避免猎奇向、过度渲染暴力的内容，优先纪录片和权威媒体解说
3. **版权边界**：视频推荐仅提供跳转链接，不嵌入播放，不暗示版权授权
4. **B站链接稳定性**：B站视频可能被UP主删除，建议优先选择官方账号或高播放量稳定视频
5. **分批提交**：每批完成后提交GitHub，避免一次性大量变更
6. **飞书同步**：本地JSON更新后需同步回飞书Base，保持双向一致
