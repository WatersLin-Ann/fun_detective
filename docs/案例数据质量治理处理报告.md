## 二、P0：页面无法展示修复

### 2.1 人物关系数组转字符串（41 个）

**问题**：详情页「人物关系」板块显示 `[object Object][object Object]...`  
**原因**：数据中 `故事视图.人物关系` 存储为数组 `[{姓名,角色,简介}]`，但详情页模板按字符串渲染。  
**修复方式**：脚本批量将数组转为格式化字符串，格式为 `**姓名**（角色）：简介`，每行一个人物。

**涉及案例分布**：
- 影视：12 个（猎头游戏、未麻的部屋、11点14分、万能钥匙、冰血暴、小岛惊魂、沉默的羔羊、盗梦空间、老无所依、谜一样的双眼、杀人回忆等）
- 推理小说：26 个（人偶馆事件、出云传说、匣中失乐、如首无作祟之物、新参者、暗黑馆事件等）
- 推理小说（英国）：2 个（九曲丧钟、俗丽之夜）
- 游戏：2 个（艾迪芬奇的记忆、锈湖天堂岛）
- 真实案件：1 个（黄道十二宫杀手）

### 2.2 关键时间线数组转字符串（11 个）

**问题**：详情页「关键时间线」板块显示 `[object Object]`  
**原因**：ZOO 短篇系列的 `故事视图.关键时间线` 存储为数组 `[{时间,事件}]`。  
**修复方式**：转为 `**时间**：事件` 格式，每行一个节点。

**涉及案例**：全部为 ZOO 短篇系列（七个房间、动物园、向阳之诗、小饰与阳子等 11 篇）。

**修复脚本**：`scripts/fix-p0-arrays.py`

## 三、P1：数据重复修复

### 3.1 欧美目录重复文件合并删除（28 组）

**问题**：同一案件在「欧美」地区和具体国家（美国/英国/法国/西班牙/约旦）各存一份，首页展示重复卡片，统计失真。  
**原因**：地区分类从「欧美」细化到具体国家后，旧的「欧美」目录文件未清理。

**修复方式**：
1. 比较欧美版与具体国家版的所有字段
2. 将欧美版独有的数据（完整故事、参考链接、关联作品等）合并到具体国家版
3. 删除欧美版文件

**合并策略**：
- 字符串字段：取更长的（更完整的版本）
- 数组字段（参考链接、推荐视频、关联作品、角色档案）：取并集去重

**涉及案例**：
- 推理小说：10 组（人性记录、啤酒谋杀案、怪屋、悬崖山庄奇案、无尽长夜、谋杀启事、阳光下的罪恶、死亡约会、漫长的告别、马耳他之鹰）
- 影视：12 组（冰血暴、小岛惊魂、搏击俱乐部、禁闭岛、穆赫兰道、第六感、老无所依、致命ID、致命魔术、记忆碎片、恐怖游轮、看不见的客人）
- 真实案件：4 组（林德伯格绑架案、莉齐·博登案、辛普森杀妻案、黑色大丽花案）
- 游戏：2 组（暴雨、黑色洛城）

> **注意**：另有 2 组同名是正常的跨类型关联（影视↔小说的告白、祈祷落幕时），不属于重复，未做处理。

**修复脚本**：`scripts/fix-p1-duplicates.py`

## 五、P3：命名不一致说明

### 5.1 文件名与案件名称不一致（13 个）

**问题**：ZOO 系列文件名带 `ZOO-` 前缀，但 JSON 内案件名称没有前缀；锈湖天堂岛、Hello Kitty 藏尸案的文件名与案件名称也有差异。

**验证结论**：**非功能性问题，未做修改**。
- slug 基于 JSON 内的 `案件名称` 生成，而非文件名
- 关联作品的站内跳转使用 slug，与文件名无关
- 文件名带前缀是为了避免文件系统中同名冲突，属于合理的命名策略
- 修改文件名可能导致 git 历史混乱和关联作品数据需要批量修正

**涉及案例**：11 个 ZOO 短篇 + 锈湖天堂岛 + Hello Kitty 藏尸案
