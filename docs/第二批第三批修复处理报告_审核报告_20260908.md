## 已核实的有效修复

### 1. 异议遮罩恢复路径

原逻辑只在 `objectionActive=true` 时显示遮罩，状态变回 false 后不隐藏。当前 `renderTrial()` 已在 false 分支重新加入 `hidden`，与 `__object()` 的 1.5 秒状态回落相匹配。

- 证据：[gameRender.js](../src/game/gameRender.js) 第 393-401 行附近。
- 审核意见：源码层面的根因已处理；仍需要真实浏览器中验证“异议 → 1.5 秒 → 遮罩消失 → 证据栏可操作”。

### 2. 关联结果弹窗与叠层时序

当前 `GameUI.showModal()` 支持 `content` 富文本；成功关联后，关联板不再以固定定时器重建，而是在结果确认回调中刷新。这消除了原先“结果正文为空、关联板覆盖确认框”的已知 P0 组合。

- 证据：[ui.js](../src/game/ui.js) 第 426-466 行附近；[evidence-board.js](../src/game/evidence-board.js) 第 320-333 行附近。
- 审核意见：实现方向正确；仍需验证确认前不会出现第二个顶层遮罩，确认后焦点可回到刷新后的关联板。

### 3. 存档对象引用修复

继续存档的代码已从替换 `state` 对象改为 `Object.assign(state, savedData)`，能够避免导出的 `GameState.state` 与内部状态引用脱节。

- 证据：[gameState.js](../src/game/gameState.js) 第 300-314 行附近。
- 审核意见：修复符合此前根因分析；但报告也承认 fresh/save/resume/reset E2E 尚未编写，不能以静态检查代替回访玩家流程验证。
