## 一、完成内容

### 1.1 玩家数据存储模块

**文件**：`src/game/playerData.js` + `public/game/playerData.js`（~280行）

**功能**：
- localStorage持久化存储，无需后端
- 自动保存，刷新页面数据不丢失
- 数据结构：证据标记、人物档案、笔记板、自定义连线、设置

**存储结构**：
```javascript
{
  caseId: 'orient-express',
  lastSaved: timestamp,
  evidenceNotes: { evidenceId: { note, tags, rating } },
  characterNotes: { characterId: { suspicion, note, relations } },
  notebook: { clues: [], reasonings: [], todos: [] },
  customLinks: [],
  settings: { autoSave, textSize }
}
```

### 1.2 推理笔记板UI

**文件**：`src/game/notebookUI.js` + `public/game/notebookUI.js`（~450行）

**三栏布局**：

| 栏目 | 功能 | 颜色标识 |
|------|------|----------|
| 🔎 我发现的线索 | 记录观察到的线索，可添加/删除 | 蓝色 |
| 💡 我的推理 | 记录玩家的推理假设，可添加/删除 | 金色 |
| ✅ 待验证 | 待办事项，可勾选完成/删除 | 绿色 |

**特性**：
- 每栏独立输入框，回车快速添加
- 待验证项支持勾选完成（划线效果）
- 鼠标悬停显示删除按钮
- 实时统计数量

### 1.3 证据自定义标记

**功能**：
- **备注**：自由文本，记录对证据的观察和推理
- **标签**：预设标签（关键证据/疑点/时间线/伪造/关联人物），可多选
- **重要程度**：5星评分，点击星号设置，再次点击取消
- 自动保存，Toast提示

### 1.4 人物档案自定义

**功能**：
- **可疑度滑块**：0-100%，实时更新，颜色随可疑度变化（绿→黄→红）
- **笔记**：自由文本，记录对人物的判断
- 人物列表展示，包含姓名和描述

### 1.5 导出/导入功能

| 导出格式 | 内容 | 用途 |
|----------|------|------|
| JSON | 完整数据备份 | 跨设备同步、备份恢复 |
| TXT | 格式化文本笔记 | 分享、打印、存档 |

**导出文件名**：`侦探笔记_orient-express_YYYY-MM-DD.json/txt`

### 1.6 游戏集成

**顶部栏新增按钮**：📝 笔记（琥珀色按钮）

**自动记录**：
- 收集证据时自动添加到"我发现的线索"栏
- 格式：`【证据】证据名：描述`

**数据暴露**：
- `window._gameEvidence` - 证据列表
- `window._gameWitnesses` - 证人列表

## 四、使用说明

### 打开笔记系统
1. 进入游戏：http://127.0.0.1:4321/fun_detective/game-design/prototype/play
2. 点击顶部栏的 **📝 笔记** 按钮
3. 在弹出的面板中切换标签页：推理笔记 / 证据标记 / 人物档案

### 快速上手
1. **收集证据**：点击场景中的证据，会自动添加到笔记板的"线索"栏
2. **记录推理**：在"我的推理"栏写下你的假设
3. **标记证据**：切换到"证据标记"页，给重要证据加星标和标签
4. **评估人物**：在"人物档案"页拖动可疑度滑块
5. **导出分享**：点击"导出"或"文本"按钮下载笔记
