## OE-P1-01：手帕竞争假设

**问题**：手帕同时是赫伯德夫人和公主的"正确"关联+矛盾，玩家穷举即可双杀。

**修复方案**：

1. **数据层**（`data-orient-express.js`）：
   - `link-handkerchief-hubbard` 标记为 `category: 'preliminary'`（初步假设），信心值从 15 降到 10，结论明确说明"这只是初步假设"
   - `link-handkerchief-princess` 添加 `requiresLink: 'link-handkerchief-hubbard'`（需先建立初步假设）、`excludesLink: 'link-handkerchief-hubbard'`（建立后排除初步假设）、`category: 'conclusion'`

2. **逻辑层**（`evidence-board.js`）：
   - `tryLink()` 中检查 `preset.requiresLink`，前置关联未建立时显示"需要更多线索"提示，不直接成功
   - `handleSuccessLink()` 中检查 `preset.excludesLink`，调用 `PlayerData.markLinkExcluded()` 标记被排除的关联

3. **数据层**（`playerData.js`）：
   - 新增 `markLinkExcluded(presetId)` 方法，给关联添加 `excluded: true` 标记

**效果**：玩家必须先建立"手帕→赫伯德"初步假设，才能验证"手帕→公主"最终结论；建立最终结论后初步假设被标记为已排除，形成完整的"假设→验证→排除"推理链。

**修复方案**（`data-orient-express.js` objectives）：

- 调查阶段（5个）：收集证据、询问证人、建立关联假设、整理笔记、准备进入审判

## OE-P1-05：评级公式重构

**问题**：评级只看信心值（100 起算，只加不减），不犯错也能 S 级。

**修复方案**（`endingUI.js calculateEnding`）：

**新公式**：综合评分 = 核心链完成度 × 40% + 矛盾发现率 × 30% + 信心值率 × 30%

**评级规则**：
| 评级 | 条件 |
|---|---|
| S | 核心链 100% + 矛盾 ≥1 + 综合 ≥85 |
| A | 核心链 ≥66% + 矛盾 ≥1 + 综合 ≥70 |
| B | 核心链 ≥33% + 综合 ≥50 |
| C | 综合 ≥30 |
| D | 其他 |

**核心链配置**（`data-orient-express.js meta.coreLinkIds`）：
- `link-watch-conductor`（死亡时间被伪造）
- `link-window-body`（逃走路线是假象）
- `link-handkerchief-princess`（复仇网络成立）

**效果**：S 级必须完成全部三条核心论证链并发现至少 1 条矛盾，单纯收集证据不再能获得高分。

## OE-P1-06：最终选择真实分支

**问题**：最终选择标为"决定结局"，但 EndingUI 只按信心选评级，未读取 final-choice。

**修复方案**（`endingUI.js`）：

1. 新增 `renderChoiceEpilogue()` 函数
2. 根据 `state.choices['final-choice']` 渲染不同后日谈：
   - `reveal`（交警方）："你向警方如实报告了12人共同作案的事实。正义得到了伸张..."
   - `conceal`（隐瞒真相）："你告诉警方凶手已从窗户逃走...波洛的内心或许永远不会平静"
3. 后日谈显示在结局描述下方，带"你的选择："标签

**效果**：玩家的道德抉择现在有明确的叙事后果，不再是伪分支。

## OE-P1-07：关联板错误组合可解释反馈

**问题**：错误组合只显示"暂时没有发现直接关联"，没有可解释的反证，鼓励穷举。

**修复方案**（`evidence-board.js handleCustomLink`）：

按组合类型给出差异化反馈：
- **证据+证据**："两者都是物证，但没有直接因果关系。试试把物证与证人关联..."
- **证人+证人**："两人证词目前没有直接矛盾。仔细对比证词细节，或者用物证检验..."
- **证据+证人**："这个物证不能直接证明该证人的说法。也许需要更多证据，或者这条线索指向另一个人..."

同时保留"已保存为自定义笔记"的提示，让玩家知道错误尝试不会被浪费。

**问题**：检测矛盾返回 0 时直接重渲染，按钮仍显示为可执行主操作，玩家不知道发生了什么。
