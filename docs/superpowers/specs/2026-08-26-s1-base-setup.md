# S1：飞书 Base 搭建手册

> 版本：v1.0  
> 日期：2026-08-26  
> 依赖：总方案 v1.0  
> 用途：照着本手册可从零搭建出「全球案件案例库」飞书多维表格

---

## 一、准备工作

1. 打开飞书，进入「云文档」→「新建」→「多维表格」
2. 命名为：**全球案件案例库**
3. 默认会有一张表，重命名为「案件库」（主表）
4. 点击底部「+」新建第二张表，命名为「线索链」（子表）

---

### 2.5 「难度综合」公式字段

飞书公式字段写法：

```
ROUND(([难度-线索密度] + [难度-误导数量] + [难度-诡计隐蔽度]) / 3, 1)
```

说明：
- 三项难度分相加后除以3，得到平均分
- `ROUND(..., 1)` 保留1位小数
- 如果飞书公式语法中字段名需要用方括号包裹，确认字段名完全一致（包括连字符）

## 七、常见问题

**Q：多选字段分组时，一条记录出现在多个组下，正常吗？**  
A：正常。飞书多选字段分组就是这样设计的，便于从不同标签维度查找。

**Q：公式字段报错怎么办？**  
A：检查字段名是否完全一致（包括空格、连字符）。飞书公式中引用字段如果有特殊字符，可能需要用方括号或反引号包裹，以飞书实际提示为准。

**Q：关联记录的双向关联怎么开？**  
A：创建「关联线索」字段时，选择关联到「线索链」表，勾选「在关联表中创建反向字段」，反向字段命名为「关联案件」。
