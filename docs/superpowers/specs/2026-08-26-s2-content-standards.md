# S2：内容采集与录入规范

> 版本：v1.0  
> 日期：2026-08-26  
> 依赖：总方案 v1.0、S1 搭建手册  
> 用途：保证案件录入的质量一致性、来源可追溯、版权合规

---

## 一、收录标准

一个案件必须满足以下**至少一条**才可收录：

1. **诡计独创性**：诡计设计有原创性，或在同类诡计中做到极致（如《嫌疑人X的献身》的不在场证明）
2. **结构代表性**：是某种叙事/案件结构的标杆（如《无人生还》的暴风雪山庄）
3. **线索链学习价值**：线索投放节奏、推理逻辑清晰，可直接参考用于游戏设计
4. **文化影响力**：在推理文化中有重要地位，被广泛引用或致敬
5. **真实悬案价值**：真实案件中假说丰富、氛围感强，适合改编参考

**不收录**：
- 诡计平庸、结构无特色的普通案件
- 仅有猎奇性但无设计价值的案件
- 信息来源不可靠、关键事实存疑且无法交叉验证的真实案件

## 二、采集渠道清单

### 2.1 推理小说
- **经典书单**：阿加莎·克里斯蒂全集、埃勒里·奎因全集、约翰·迪克森·卡尔（密室之王）、岛田庄司、绫辻行人、东野圭吾、横沟正史、松本清张
- **国产推理**：紫金陈、呼延云、雷米、秦明、那多
- **参考资源**：豆瓣推理小说 Top100、「不可能犯罪」书单、各推理出版社（新星出版社「午夜文库」、群众出版社）

### 2.2 真实案件
- **国内**：中国裁判文书网（已结案判决书）、公安部公开通报、正规媒体深度报道（三联生活周刊、南方周末等）
- **国际**：FBI 公开档案、Wikipedia 著名案件条目、Court TV 公开资料、《犯罪档案》类正规出版物
- **悬案**：专门整理悬案的正规书籍/网站（如《The Encyclopedia of Unsolved Crimes》），需交叉验证

### 2.3 影视
- **剧集**：《真探》《神探夏洛克》《犯罪心理》《信号》《隐秘的角落》《沉默的真相》
- **电影**：《七宗罪》《消失的爱人》《调音师》《控方证人》
- **注意**：优先选择案件结构完整、诡计有设计感的作品，纯 procedural（流程式破案）的单元剧价值较低

### 2.4 游戏
- **文字推理**：《逆转裁判》系列、《弹丸论破》系列、《极限脱出》系列
- **解谜探索**：《极乐迪斯科》《Return of the Obra Dinn》《Her Story》
- **注意**：重点拆解游戏化推理机制（证据矛盾、选择分支、信息投放节奏），而非仅看剧情

### 2.5 历史谜案/都市传说
- 历史谜案需有正规历史研究资料支撑
- 都市传说需标注「传说性质」，不做事实断言

## 三、信息来源标注规范

### 3.1 来源记录位置
在主表「备注」字段中，按以下格式记录参考来源：

```
【参考来源】
1. [书籍] 阿加莎·克里斯蒂《无人生还》，新星出版社，2019版
2. [网页] https://xxx（访问日期：2026-08-26）
3. [影视] 《真探》第一季，HBO，2014，第1-8集
```

### 3.2 来源类型标签
- `[书籍]`：书名 + 作者 + 出版社 + 版本/年份
- `[网页]`：URL + 访问日期 + 网站名
- `[影视]`：作品名 + 出品方 + 年份 + 涉及集数
- `[游戏]`：游戏名 + 开发商 + 发行年份 + 涉及章节
- `[档案]`：档案机构 + 档案编号/名称（如适用）

### 3.3 真实案件可靠性等级
真实案件在「备注」中标注可靠性等级：
- **A级**：有官方档案/判决书/权威媒体深度报道，事实可靠
- **B级**：有正规出版物整理，但部分细节来自二手资料
- **C级**：主要来自网络整理，关键事实需标注"据XX来源称"

## 四、版权与伦理规则

### 4.1 虚构作品
- **故事必须用自己的话改写**，禁止大段原文摘抄（单句引用不超过30字，且需标注引用）
- 标注原作者和作品名称
- 诡计分析、线索拆解属于评论性使用，可自由展开

### 4.2 真实案件
- 使用公开信息，不披露受害者及其家属的隐私信息（如真实身份证号、住址、未公开的亲属信息）
- 未结案案件不做「某人就是凶手」的断言，只列假说并标注「假说」
- 涉及未成年人的案件，特别注意保护隐私，避免细节描写

### 4.3 图片素材
- MVP 阶段不录入图片，纯文本
- 后续如需配图，使用正版素材或自行绘制，不用来源不明的图片

## 五、故事写作规范

### 5.1 文风
- **整体风格**：悬疑感叙事，客观中带氛围，不做过度文学化渲染
- **视角**：第三人称全知视角，或模拟侦探视角；避免第一人称（除非原作核心是叙述性诡计）
- **语言**：中文，简洁有力，避免网络用语和口语化表达

### 5.2 各字段写作要求

#### 一句话简介
- 50字以内
- 概括案件核心冲突，不含剧透
- 示例：「十个人被邀请到孤岛，随后按照童谣逐一死去，无人生还。」

#### 故事摘要
- 200字以内
- 介绍案件背景和核心谜题，**绝对不含结局和真相**
- 结尾可留悬念钩子

#### 完整故事
- **字数**：800-2000字
- **结构**：
  1. 背景铺垫（人物、场景、起因）
  2. 案件发生
  3. 调查过程（关键线索出现、疑点浮现）
  4. 转折/高潮
  5. 结局部分前加分割线标记：`--- 以下含结局 ---`
- **要求**：保留悬念感，关键线索自然融入叙事，不提前揭示真相
- **悬案处理**：写到调查陷入僵局为止，结局部分写「至今未破」，然后在「结局/真相」字段列假说

#### 人物关系
- 格式：
  ```
  【受害者】：姓名（身份，简要特征）
  【侦探/调查者】：姓名（身份，办案风格）
  【主要嫌疑人】：
  - 姓名（身份，与受害者关系，可疑点）
  - 姓名（身份，与受害者关系，可疑点）
  【关键证人】：姓名（身份，提供了什么信息）
  ```
- 真实案件中如受害者姓名需要保护，可用「受害者A」代替

#### 关键时间线
- 按时间顺序列出，格式：
  ```
  - X月X日：事件描述
  - X月X日：事件描述
  ```
- 时间不明确的用「案发前」「案发时」「案发后第X天」

#### 结局/真相
- **已破案/虚构结局**：清晰写出真相、凶手身份、作案手法、动机
- **悬案**：列出主流假说，每条标注：
  ```
  【假说A】假说名称
  核心观点：……
  支持证据：……
  疑点：……
  ```

## 六、设计视图填写规范

### 6.1 核心诡计简述
- 一句话，30字以内
- 说清「用了什么手法 + 达到了什么效果」
- 示例：「利用替身尸体和时间差制造不在场证明，让凶手在案发时间出现在另一城市。」

### 6.2 诡计类型
- 至少选1个，可多选
- 如果诡计跨类型，选最核心的1-2个即可，不要全选

### 6.3 信息差分析
- **固定三段式 + 分析**：
  ```
  【读者/玩家已知】：读者在故事前期能掌握的信息
  【侦探已知】：侦探通过调查掌握但读者尚未知晓的信息（如有）
  【真相】：完整事实
  【信息差设计分析】：说明这种信息差如何制造悬念、误导读者、或在游戏中转化为解谜乐趣
  ```
- 如果是全知视角叙事，「侦探已知」可写「与读者同步」

### 6.4 红鲱鱼/误导
- 每条误导单独列出，格式：
  ```
  1. 假线索：线索内容
     指向错误结论：……
     布置手法：作者如何让读者相信这个假线索
  ```
- 如果案件没有明显误导，填「无明显红鲱鱼，主要靠信息差制造悬念」

### 6.5 难度评分校准

**评分维度定义**：

| 维度 | 1分 | 3分 | 5分 |
|---|---|---|---|
| 线索密度 | 线索极少，几乎靠推理 | 线索适中，关键线索3-5条 | 线索极多，需要筛选大量信息 |
| 误导数量 | 无误导 | 2-3个误导线索 | 误导密集，真假难辨 |
| 诡计隐蔽度 | 诡计很容易猜到 | 需要仔细推理才能识破 | 极难识破，有反转再反转 |

**锚点案例**（用于校准评分手感）：
- **低难度（综合≈2分）**：柯南动画早期单集案件（线索明显、误导少）
- **中难度（综合≈3分）**：阿加莎《东方快车谋杀案》（有误导但核心诡计有迹可循）
- **高难度（综合≈4.5分）**：《嫌疑人X的献身》（诡计隐蔽度极高，误导精心设计）
- **极高难度（综合≈5分）**：《占星术杀人魔法》（诡计独创性极高，极难提前识破）

**评分原则**：
- 三项独立评分，不受其他维度影响
- 取整数分（1-5），综合分由公式自动计算
- 评分时参考锚点案例，避免个人感觉偏差

## 七、线索链录入标准

### 7.1 线索类型定义

| 类型 | 定义 | 示例 |
|---|---|---|
| 关键线索 | 直接指向真相或对推理起决定性作用的线索 | 「嫌疑人的手表慢了15分钟」→ 指向时间诡计 |
| 误导线索 | 故意引导读者/玩家走向错误结论的假线索 | 「在嫌疑人房间发现带血的刀」→ 但刀是被嫁祸的 |
| 背景信息 | 不直接指向真相，但对理解案件环境/人物动机有帮助 | 「受害者生前曾诈骗多人」→ 提供动机背景 |

### 7.2 录入粒度
- 每个案件至少录入 **3条线索**（关键线索≥1、误导线索≥1、背景信息≥1）
- 复杂案件可录入5-10条
- 一条线索只表达一个信息点，不要把多个线索合并

### 7.3 字段填写规范

**线索内容**：
- 客观描述线索本身，不加入推理
- 示例：「案发时间22:00，嫌疑人21:55在便利店有监控记录」（✓）
- 反例：「嫌疑人有不在场证明但可能是伪造的」（✗，这是推理不是线索）

**指向结论**：
- 关键线索：写这条线索能推出的结论方向
- 误导线索：写「指向错误结论：XXX」
- 背景信息：写「补充背景：XXX」

**出现时机**：
- 开篇：故事开始就出现
- 前期：案件发生后第一轮调查
- 中期：调查深入阶段
- 后期：接近真相前
- 终局：解谜时才揭示的线索

## 八、录入流程

### 步骤1：新建案件记录
- 填写「基本信息」8个字段
- 「录入状态」设为「待录入」

### 步骤2：录入故事视图
- 按顺序：一句话简介 → 故事摘要 → 完整故事 → 人物关系 → 关键时间线 → 结局/真相
- 完成后「录入状态」改为「故事完成」

### 步骤3：录入设计视图
- 按顺序：核心诡计简述 → 诡计类型 → 可复用机制 → 信息差分析 → 红鲱鱼/误导 → 三项难度评分
- 完成后「录入状态」改为「设计完成」

### 步骤4：录入线索链
- 切换到「线索链」表，逐条添加
- 每条线索关联到对应案件
- 至少3条（关键/误导/背景各1）

### 步骤5：填写来源与备注
- 在「备注」字段填写参考来源（格式见第三节）
- 真实案件标注可靠性等级

### 步骤6：自检
- 对照「录入自检清单」逐项检查
- 通过后「录入状态」改为「完整」

## 九、录入自检清单

每条案件标记「完整」前必须通过：

### 基本信息
- [ ] 案件名称已填
- [ ] 来源类型已选
- [ ] 来源作品/事件已填
- [ ] 地区已选
- [ ] 年代已选
- [ ] 案件状态已选
- [ ] 一句话简介在50字以内且不含剧透

### 故事视图
- [ ] 故事摘要在200字以内且不含剧透
- [ ] 完整故事在800-2000字，有悬念感
- [ ] 完整故事结局前有「--- 以下含结局 ---」标记
- [ ] 人物关系覆盖所有主要角色
- [ ] 结局/真相清晰（悬案有假说标注）

### 设计视图
- [ ] 核心诡计简述一句话能说清
- [ ] 诡计类型至少选1个
- [ ] 信息差分析有完整三段（读者/侦探/真相）+ 分析
- [ ] 红鲱鱼/误导已填（无则注明）
- [ ] 三项难度评分已填（1-5整数）
- [ ] 难度综合自动计算正常

### 线索链
- [ ] 至少3条线索
- [ ] 关键线索≥1条
- [ ] 误导线索≥1条
- [ ] 背景信息≥1条
- [ ] 每条线索都关联到了案件
- [ ] 每条线索的「指向结论」已填

### 来源与管理
- [ ] 备注中有参考来源记录
- [ ] 真实案件标注了可靠性等级
- [ ] 录入状态改为「完整」

## 十、质量审核机制

### 10.1 自检（必做）
- 录入者完成后必须通过自检清单

### 10.2 交叉审核（首批10个案例必做）
- 首批案例每个完成后，由第二人快速通读
- 重点检查：事实准确性、剧透标记、难度评分合理性、线索链完整性
- 审核通过后才正式标记「完整」

### 10.3 定期复盘
- 每录入10个案例做一次复盘
- 检查：字段是否够用、标签是否需要扩充、难度评分是否需要校准、写作规范是否需要调整
