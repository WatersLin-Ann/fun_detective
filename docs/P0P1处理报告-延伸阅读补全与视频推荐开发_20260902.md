### 2.2 特殊处理：ZOO子案件继承修复

ZOO系列的11个子案件（七个房间、动物园、向阳之诗、在即将坠落的飞机中、寒冷森林中的小白屋、小饰与阳子、把血液找出来、神的咒语、衣橱、远离的夫妇、从前在太阳西沉的公园里）在从父案件拆分时丢失了参考链接。

**处理方式**：继承父案件 `ZOO.json` 的参考链接（维基百科 - ZOO小说 + 豆瓣 - ZOO），因为子案件属于同一本短篇集，共享相同的来源作品信息。

### 2.3 链接策略说明

由于111个案件的豆瓣/IMDb/Steam准确subject ID无法批量获取，采用以下策略：

- **维基百科**：基于案件名称构造直接链接（`https://zh.wikipedia.org/wiki/名称`），大部分知名作品均有对应页面
- **豆瓣/IMDb/Steam**：使用搜索链接（如 `https://search.douban.com/book/subject_search?search_text=名称`），确保点击后可跳转到搜索结果页，用户可从中找到准确的subject页面
- **百度百科**：基于名称构造直接链接

**后续建议**：搜索链接可在后续人工精修时替换为准确的subject页面链接。本次优先保证100%覆盖率和可访问性。

## 三、P1 执行结果：视频推荐功能开发

### 3.1 数据模型扩展（types.ts）

新增 `RelatedVideo` 接口：

```typescript
export interface RelatedVideo {
  标题: string;
  URL: string;
  来源: 'B站' | 'YouTube' | '其他';
  时长?: string;
  简介?: string;
  视频类型?: '解说' | '纪录片' | '预告片' | '实况' | '评测' | '其他';
}
```

在 `BasicInfo` 中新增可选字段：
```typescript
推荐视频?: RelatedVideo[];
```

### 3.2 前端渲染模块（[...slug].astro）

在案件详情页的**延伸阅读模块之后、相关案例推荐之前**，新增"相关视频推荐"模块：

- **展示条件**：`基本信息.推荐视频` 非空时显示
- **布局**：响应式卡片网格（桌面3列 / 平板2列 / 手机1列）
- **卡片内容**：视频来源图标、标题、简介、来源标签、视频类型标签、时长
- **交互**：点击卡片新窗口打开视频链接，hover时有边框和背景色变化
- **降级**：无视频数据时不渲染模块，不影响页面布局

### 3.3 首批内容填充（30个热门案件）
