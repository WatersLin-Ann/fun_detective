## 总体策略

**核心原则**: 先修 "能不能玩"（P0），再修 "好不好玩"（P1），最后修 "精不精致"（P2）。每阶段独立可验收，不跨阶段耦合。

**设计方向锁定**:



* **视觉**: 深色沉浸式游戏壳（近黑底 #0d0d12 + 案件主题色点缀），与主站浅色页面通过 "档案室" 过渡带衔接

* **交互**: 上下文感知工具条（当前阶段只显示相关操作），所有弹层统一焦点管理，所有状态变更有 aria-live 播报

* **图标**: 系统操作统一 Lucide 线性 SVG，emoji 仅保留内容性装饰

* **触控**: 主操作 ≥44×44px，移动端底部工具栏替代顶部拥挤条

