## 一、问题清单

### 🔴 P0 严重（功能不可用 / 卡死）

| # | 位置 | 问题描述 | 根因 | 修复方案 |
|---|---|---|---|---|
| 1 | 游戏设计 → 关卡生成器 | 页面脚本启动即崩溃，选案例/选模板/生成全部失效 | `<script type="application/json">` 内的 `{JSON.stringify(templates)}` 在 Astro 中不会被渲染，原样输出字面文本 → `JSON.parse` 抛 `SyntaxError` → 模块中断；且客户端调用的 `generateLevelStructure`/`exportToMarkdown`/`exportToJSON`/`downloadFile` 只在 frontmatter import，客户端未定义；生成前还残留调试 `alert()` | 移除 JSON 注入脚本，改为在客户端 `<script>` 中直接 `import { gameTemplates } from '@data/game-templates'` 和生成器函数；删除 alert |
| 2 | 游戏设计 → 可玩原型《东方快车》 | 游戏 100% 卡死，永远进不了审判阶段 | 进入审判要求"3 证据 + 3 证人"，但调查阶段只开放走廊（2 证人）和受害者包厢（0 证人），其余 4 证人在被门槛挡住的餐车里 → 证人最多 2/3 | 将证人门槛降为 2，同步更新开场对话和弹窗文案 |
| 3 | 线上站点数据 | 首页显示 146 条，cases 目录现有 165+ 条且仍在增长；新案件（聂树斌案、张子强案等）详情页 404 | `dist` 构建于 22:06，22:30 后新同步的案件未纳入；本地静态服务不自动重建 | 代码修复后重新 `npm run build`，重启 server.js |
