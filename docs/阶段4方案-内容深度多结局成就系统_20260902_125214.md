## 一、系统目标

### 核心价值
1. **增加 replay value**：不同选择和表现触发不同结局，鼓励多次游玩
2. **增强成就感**：成就系统奖励玩家的探索和推理
3. **明确反馈**：结局评级让玩家清楚自己的推理水平
4. **内容深度**：丰富游戏结束后的体验，不只是"通关"

### 设计原则
- **结局有意义**：不同结局有不同的剧情内容，不只是文字差异
- **成就可追求**：成就条件明确，玩家可以针对性挑战
- **评级有区分度**：S/A/B/C/D五级，体现推理水平差异
- **统计有价值**：通关统计展示玩家的游戏过程数据

## 二、多结局系统

### 2.1 结局类型

| 结局 | 条件 | 说明 |
|------|------|------|
| S级 - 完美推理 | 信心值≥90 + 发现所有矛盾 | 完全揭露真相，所有细节正确 |
| A级 - 出色推理 | 信心值≥75 + 发现大部分矛盾 | 基本揭露真相，少量细节遗漏 |
| B级 - 合格推理 | 信心值≥60 | 找到凶手，但推理过程有瑕疵 |
| C级 - 勉强推理 | 信心值≥40 | 结论正确但证据不足 |
| D级 - 推理失败 | 信心值<40 或 选择错误 | 未能揭露真相，案件成谜 |

### 2.2 结局内容

每个结局包含：
- **结局标题**：如"完美的审判"、"遗憾的推理"
- **结局描述**：详细的剧情收尾
- **侦探评价**：波洛/福尔摩斯对玩家推理的评价
- **遗漏提示**：如果有未发现的内容，提示玩家
- **解锁成就**：根据结局解锁对应成就

### 2.3 最终选择影响

在审判的最终选择阶段，玩家的选择会影响结局：
- 选择正确的凶手 + 正确的动机 → 正常评级
- 选择错误的凶手 → D级结局
- 选择正确凶手但错误动机 → 降低一级评级

## 三、成就系统

### 3.1 成就类型

| 类型 | 说明 | 示例 |
|------|------|------|
| 进度成就 | 完成游戏流程 | 首次通关、完成所有案件 |
| 探索成就 | 收集特定内容 | 收集所有证据、询问所有证人 |
| 推理成就 | 发现特定内容 | 发现所有矛盾、发现时间线矛盾 |
| 技巧成就 | 特定玩法方式 | 不使用提示通关、快速通关 |
| 结局成就 | 触发特定结局 | S级结局、全结局收集 |

### 3.2 成就列表（基础版本）

| 成就 | 条件 | 稀有度 |
|------|------|--------|
| 初出茅庐 | 首次通关任意案件 | 普通 |
| 证据收藏家 | 收集案件中所有证据 | 稀有 |
| 审讯专家 | 询问案件中所有证人 | 稀有 |
| 矛盾猎手 | 发现案件中所有矛盾 | 史诗 |
| 时间侦探 | 发现所有时间线矛盾 | 史诗 |
| 关键词大师 | 发现案件中所有关键词 | 稀有 |
| 完美推理 | 获得S级结局 | 传说 |
| 连续通关 | 完成所有可用案件 | 传说 |

### 3.3 成就展示

- 游戏结束时展示本次解锁的成就
- 案件选择页显示总成就进度
- 成就弹窗动画（解锁时）

## 四、结局评级和通关统计

### 4.1 评级展示

游戏结束后显示：
- 大字号评级（S/A/B/C/D）
- 评级描述
- 信心值最终得分
- 侦探评价

### 4.2 通关统计

| 统计项 | 说明 |
|--------|------|
| 游戏时长 | 从开始到结束的时间 |
| 收集证据 | 已收集/总数 |
| 询问证人 | 已询问/总数 |
| 发现矛盾 | 已发现/总数 |
| 证据关联 | 成功关联次数 |
| 时间线事件 | 已发现/总数 |
| 关键词 | 已发现/总数 |
| 出示证据 | 审判中出示次数 |
| 最终信心值 | 0-100 |

### 4.3 重玩鼓励

- 显示"还有X个结局未解锁"
- 显示"还有X个成就未解锁"
- "再玩一次"按钮

## 七、风险和注意事项

### 风险1：结局内容编写工作量大
- **问题**：5个结局每个都需要详细剧情
- **解决**：基础版本先做评级差异，剧情内容逐步丰富

### 风险2：成就条件判断复杂
- **问题**：部分成就条件需要追踪多个数据
- **解决**：基础版本只做容易判断的成就

### 风险3：存档兼容性
- **问题**：旧存档没有新字段
- **解决**：初始化时设置默认值

### 注意事项
- 结局评级要公平，信心值计算要合理
- 成就解锁要有明确的反馈
- 通关统计要准确
- 重玩时要重置相关状态
