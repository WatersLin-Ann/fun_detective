# 血字的研究 — 可玩性、逻辑性与趣味性审查报告

> 审查日期：2026-09-08
> 审查范围：`src/game/data-study-in-scarlet.js` + 核心逻辑（gameInteractions / gameRender / endingUI）
> 审查方法：静态代码审查 + 逻辑推演 + 与东方快车修复方案交叉对比
> 案件 ID：`study-in-scarlet`
> 流程类型：investigation-trial（调查+审判）

---

## 一、总体结论

| 维度 | 评分 | 说明 |
|---|---|---|
| 可玩性 | **4/10** | 存在 2 个 P0 阻断级 Bug，玩家无法通关 |
| 逻辑性 | **5/10** | 证据链基本完整，但有来源标注错误和无法触发的矛盾 |
| 趣味性 | **6/10** | 节奏尚可，但审判阶段目标过少、结局无分支、评级天花板 |

**核心问题**：东方快车修复时引入的「综合评级公式」和「审判门槛检查」未同步到血字的研究，导致该案件出现评级天花板和审判死锁。

## 二、P0 阻断级问题（必须修复）

### SIS-P0-01：审判门槛死锁 — 永远无法进入审判

**问题描述**：
- `meta.trialRequirement.requireContradiction = true`
- 进入审判前必须 `contradictionsFound.length >= 1`
- 但矛盾只能在**审判阶段**通过「异议！」系统触发（`gameRender.js:547` 仅在 trial 证人质询界面渲染异议按钮）
- 形成死锁：**需要矛盾才能进审判 → 矛盾只能在审判中发现**

**影响**：玩家收集完所有证据、询问完所有证人后，点击「开始审判」会被提示「需要发现至少1个证词矛盾」，但调查阶段没有任何方式可以发现矛盾。游戏完全无法推进。

**代码定位**：
- `data-study-in-scarlet.js:374` — `requireContradiction: true`
- `gameInteractions.js:169` — 门槛检查
- `gameRender.js:547` — 异议按钮仅在审判阶段渲染

**修复方案**（三选一）：
1. **推荐**：将 `requireContradiction` 改为 `false`，与东方快车一致（东方快车靠关联板进入审判）
2. 在调查阶段增加「笔记矛盾检测」功能，允许玩家在笔记中对比证词发现矛盾
3. 在调查阶段增加「初步异议」机制，允许对证人证词提出疑问

---

### SIS-P0-02：评级天花板 — 最高只能获得 C 级

**问题描述**：
- 东方快车修复时，评级公式改为「核心链40% + 矛盾30% + 信心30%」综合评分
- S/A/B 级均要求 `coreCompletionRate >= 阈值`
- 但血字的研究 `meta.coreLinkIds` **未配置**（空数组）
- `coreCompletionRate = coreLinkIds.length > 0 ? ... : 0` → 恒为 0
- 结果：S级（需≥1.0）、A级（需≥0.66）、B级（需≥0.33）**永远无法达成**
- 玩家最高只能获得 C 级（compositeScore ≥ 0.3）

**影响**：成就「完美推理」（S级结局）和「证据关联大师」无法解锁；评级系统形同虚设；玩家努力无法获得对应反馈。

**代码定位**：
- `endingUI.js:22-24` — coreLinkIds 读取与计算
- `endingUI.js:40-49` — 评级门槛
- `data-study-in-scarlet.js:363-387` — meta 中缺少 coreLinkIds

**修复方案**：
在 `meta` 中添加 `coreLinkIds`，选取 3 条核心论证链：
```js
coreLinkIds: [
  'link-bloodword-lestrade',   // 血字真相（复仇而非人名）
  'link-ring-messenger',       // 戒指诱饵（引出马车夫）
  'link-carriage-passerby'     // 马车夫身份（私人马车+目击者）
],
minContradictions: 1
```

## 三、P1 重要问题（影响体验）

### SIS-P1-01：调查目标 phase 错误

**问题描述**：
- `obj-sis-004`「发现证词矛盾」`phase: 'investigation'`
- 但矛盾只能在审判阶段触发
- 玩家在调查阶段永远无法完成该目标，目标列表长期显示未完成

**修复方案**：将 `obj-sis-004` 的 phase 改为 `'trial'`，并在调查阶段新增「建立线索关联」目标（type: `create_link`）。

---

### SIS-P1-02：矛盾 c3 无法触发

**问题描述**：
- 矛盾列表定义了 4 个矛盾：c1（lestrade+blood-word）、c2（passerby+footprints）、c3（lestrade+body）、c4（messenger+ring）
- 但 `lestrade.contradiction` 只配置了 `evidenceId: 'blood-word'`
- 异议系统匹配逻辑：`witness.contradiction.evidenceId === selectedEvidence`（`gameInteractions.js:297`）
- 玩家对 lestrade 出示 `body` 证据时，不会匹配，c3 永远无法触发
- 成就「矛盾猎手」（发现所有矛盾）无法达成

**修复方案**：将证人的 `contradiction` 字段改为数组结构，支持多个矛盾：
```js
contradictions: [
  { evidenceId: 'blood-word', revealedText: '...' },
  { evidenceId: 'body', revealedText: '...' }
]
```
并同步修改 `gameInteractions.js:297` 的匹配逻辑为数组查找。

---

### SIS-P1-03：时间线来源标注错误（2处）

**问题描述**：

| 事件 | 标注来源 | 实际问题 |
|---|---|---|
| tl-sis-001「锥伯到达伦敦」 | `body`（尸体） | 尸体无法证明死者何时到达伦敦 |
| tl-sis-002「锥伯在酒馆」 | `passerby`（路人） | 路人证词中没有提到酒馆，只说看到高个子从空屋出来 |

**影响**：时间线「来源可追溯」的设计目标失效，玩家点击来源时跳转到不相关的证据/证人，降低信任感。

**修复方案**：
- tl-sis-001：来源改为 `lestrade`（警方调查报告），或删除该事件
- tl-sis-002：来源改为 `watson`（华生的酒馆调查），或修改路人证词增加酒馆内容

---

### SIS-P1-04：时间线矛盾引用不存在的尸检报告

**问题描述**：
- `tc-sis-002` 描述：「尸检显示死亡时间约在23:00-00:00」
- 但游戏中**没有尸检报告**这个证据，证人证词中也没有提到死亡时间
- 玩家无法验证这个矛盾的依据

**修复方案**：
1. 在 `body` 证据的 keyInfo 中增加死亡时间推断：「根据尸斑和体温，死亡时间约在23:00-00:00」
2. 或将 tc-sis-002 的描述改为基于已有证据的表述

---

### SIS-P1-05：预设关联 link-cigar-body 逻辑链不完整

**问题描述**：
- `link-cigar-body`（cigar-ash → body）结论：「送信小孩说马车夫抽印度雪茄，进一步印证了他的身份」
- 但该关联只涉及两个证据（cigar-ash 和 body），**不包含 messenger 证人**
- 玩家建立这条关联时，还没有询问 messenger，结论中却引用了 messenger 的证词
- 逻辑上：cigar-ash 只能证明「凶手抽印度雪茄」，不能直接证明「马车夫是凶手」

**修复方案**：
- 将该关联改为 `cigar-ash → messenger`（证据→证人），结论为「现场的印度雪茄烟灰与送信小孩描述的马车夫习惯一致」
- 或增加前置关联要求：需先建立 `link-ring-messenger` 后才能建立此关联

---

### SIS-P1-06：审判阶段目标过少

**问题描述**：
- 审判阶段只有 2 个目标：质询所有证人、出示证据2次
- 缺少「发现矛盾」「完成总结陈词」「进入结局」等关键节点目标
- 玩家在审判阶段缺乏进度感和方向感

**修复方案**：新增审判目标：
```js
{ id: 'obj-sis-008', phase: 'trial', title: '发现证词矛盾', type: 'find_contradiction', target: 1 },
{ id: 'obj-sis-009', phase: 'trial', title: '完成总结陈词', type: 'closing_statement', target: 1 }
```

---

### SIS-P1-07：intro 场景无法访问

**问题描述**：
- `meta.firstScene = 'crime-scene'`，游戏直接从案发现场开始
- `intro` 场景（贝克街221B开场对话）永远不会被访问
- intro 场景中精心编写的 6 句开场对话（福尔摩斯收到求助信）完全浪费
- 玩家缺少「接受案件→前往现场」的叙事过渡

**修复方案**：将 `meta.firstScene` 改为 `'intro'`，让玩家先经历开场对话，再通过 exit 进入 crime-scene。

---

### SIS-P1-08：无最终选择分支

**问题描述**：
- 东方快车已实现「最终选择」机制（reveal/conceal 影响结局叙事）
- 血字的研究没有 `final-choice` 配置，结局完全由评级决定
- 原著名场面：福尔摩斯抓住凶手后，凶手讲述复仇动机，然后因动脉瘤死亡
- 可以增加选择：「将凶手交给警方」vs「听他说完故事」，影响结局叙事

**修复方案**：在审判结束后增加选择节点，参考东方快车的 `renderChoiceEpilogue()` 实现。

## 四、P2 打磨问题

### SIS-P2-01：时间线矛盾信心值过低

- `tc-sis-001` 信心+15，`tc-sis-002` 信心+10
- 对比：证人矛盾信心+20，预设关联信心+15~20
- 时间线矛盾的发现难度不低，但回报偏低，玩家缺乏动力去检测时间线矛盾

**建议**：统一提升到 +20，与证人矛盾持平。

---

### SIS-P2-02：关键词触发机制不明确

- 6 个关键词中，5 个 `unlockType: 'dialog'`，1 个 `unlockType: 'confidence'`
- `dialog` 类型的触发条件未在数据中说明：是特定对话后自动解锁？还是玩家在笔记中输入关键词？
- 玩家无法理解如何主动解锁关键词

**建议**：在关键词配置中增加 `trigger` 字段，明确触发条件（如「询问 lestrade 后解锁」「信心值达到30后解锁」）。

---

### SIS-P2-03：调查阶段无关联板引导目标

- 案件有 5 条预设关联，但调查目标中没有「建立线索关联」的目标
- 玩家可能不知道有关联板功能，或不知道应该建立哪些关联
- 与东方快车的目标设计不一致（东方快车有「建立关联假设」目标）

**建议**：新增调查目标 `type: 'create_link', target: 2`。

---

### SIS-P2-04：证人华生在审判中质询价值低

- `watson.contradiction = null`，无法对其提出异议
- 华生的证词是辅助性的（确认毒杀、戒指计划），没有矛盾点
- 审判中质询华生只能获得信息，无法推进矛盾发现

**建议**：给华生增加一个「温和矛盾」——例如华生说「福尔摩斯说戒指是关键」，但玩家可以出示证据说明戒指的真正用途，触发一个小的推理修正（不降低信心，反而增加）。

---

### SIS-P2-05：场景 street 内容单薄

- 花园街场景只有 2 个交互物（马车痕迹、路人）
- 对比 crime-scene 有 6 个交互物，street 显得空旷
- 玩家在该场景停留时间短，缺乏探索感

**建议**：增加 1-2 个环境交互物（如「泥泞的地面」「街灯」「隔壁房屋」），提供氛围描述或次要线索。
