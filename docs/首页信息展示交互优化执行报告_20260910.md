## 三、优化项详情

### 3.1 游戏入口屏蔽（线上/本地区分）

**实现方式**：使用 Astro 的 `import.meta.env.DEV` 构建时判断

- **BaseLayout**：导航栏和 footer 的「游戏设计」链接用 `{isDev && ...}` 条件渲染，线上构建时不输出
- **prototype/index.astro**：线上环境显示全屏遮罩（🔒 游戏原型内部测试中），提供「返回案件资料库」按钮
- **prototype/play.astro**：同上，z-index 设为 100 确保覆盖游戏加载态
- **本地环境**（`astro dev`）：所有游戏入口正常显示，无遮罩

**验证**：构建产物中 `index.html` 不含「游戏设计」导航链接；`prototype/index.html` 含遮罩 DOM。

#### 新增「延伸阅读」引导

在卡片底部元信息上方新增：
```
📖 2篇资料 · 🎬 1个视频
```

- 数据来源：`基本信息.参考链接`（数量）+ `基本信息.推荐视频`（数量）
- 仅在有数据时显示，无数据时隐藏
- 图标使用 inline SVG（非 emoji），满足可访问性要求

#### 移动端横向布局

断点 `max-width: 768px`：
- 卡片从 `flex flex-col` 改为 `flex flex-row`
- 封面区：`width: 40%`，高度自适应
- 内容区：`width: 60%`，`padding: 12px`
- 图标缩小到 `32px`

**预期效果**：移动端单卡高度从 ~340px 降至 ~160px，一屏可展示 3-4 张卡片。

### 3.4 瀑布流 + 无限滚动

#### 瀑布流布局

从 CSS Grid 改为 CSS Columns：
```css
.case-masonry {
  column-count: 1;
  column-gap: 16px;
}
@media (min-width: 768px) { .case-masonry { column-count: 2; } }
@media (min-width: 1024px) { .case-masonry { column-count: 3; } }
.case-masonry > article {
  break-inside: avoid;
  margin-bottom: 16px;
  display: inline-block;
  width: 100%;
}
```

#### 无限滚动

- 在列表底部放置 `#scroll-sentinel` 哨兵元素
- `IntersectionObserver` 监听哨兵，`rootMargin: 300px` 提前触发
- 触发时自动点击「加载更多」按钮（复用现有分页逻辑）
- 全部加载完成后，哨兵替换为「已加载全部案件」提示
- 「加载更多」按钮保留作为 JS 禁用时的降级方案

#### 分页参数

- 每页数量：`12` → `50`
- 202 条案件只需 5 页即可加载完成

### 3.5 回到顶部按钮

- 位置：右下角固定，`bottom: 24px; right: 24px`
- 尺寸：`44px × 44px`（满足触控最小尺寸）
- 触发：滚动超过 500px 时淡入，回到顶部后淡出
- 点击：`window.scrollTo({ top: 0, behavior: 'smooth' })`
- 样式：圆形按钮，主色背景，向上箭头 SVG 图标
- 可访问性：`aria-label="回到顶部"`，`:focus-visible` 有 outline
