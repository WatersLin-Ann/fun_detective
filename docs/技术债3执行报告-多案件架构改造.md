### 5. 游戏页通用化改造

**文件**：`src/pages/game-design/prototype/play.astro`

**改造内容**：

#### 5.1 动态加载案件数据
```javascript
const urlParams = new URLSearchParams(window.location.search);
const currentCaseId = urlParams.get('case') || 'orient-express';

function loadCaseData(caseId, callback) {
  const caseConfig = (window.GameCases || []).find(c => c.id === caseId);
  const script = document.createElement('script');
  script.src = caseConfig.dataFile;
  script.onload = () => callback();
  document.head.appendChild(script);
}
```

#### 5.2 数据加载后初始化
```javascript
function init() {
  const caseData = window.GameData;
  gameScenes = caseData.scenes;
  gameEvidence = caseData.evidence;
  // ... 从案件数据获取所有游戏数据
  render();
}
loadCaseData(currentCaseId, () => { init(); });
```

#### 5.3 返回按钮
- 顶部栏"← 返回"按钮已指向案件选择页

### 6. 存档隔离

**问题**：原来所有案件共用一个存档key，切换案件会覆盖存档。

**解决方案**：存档key包含案件ID

#### 6.1 游戏进度存档
```javascript
const SAVE_KEY = `fun-detective-save-${currentCaseId}`;
// 例：fun-detective-save-orient-express
```

#### 6.2 玩家数据存档（笔记/标记/关联）
**文件**：`src/game/playerData.js`

```javascript
let currentCaseId = 'orient-express';
let STORAGE_KEY = `fun-detective-player-data-${currentCaseId}`;

function setCaseId(caseId) {
  currentCaseId = caseId || 'orient-express';
  STORAGE_KEY = `fun-detective-player-data-${currentCaseId}`;
}
```

在play.astro的init中调用：
```javascript
PlayerData.setCaseId(currentCaseId);
```

**效果**：
- ✅ 不同案件的游戏进度完全隔离
- ✅ 不同案件的笔记/证据标记/关联记录完全隔离
- ✅ 导出文件名包含案件ID（`侦探笔记_orient-express_2026-09-02.json`）

## 五、如何添加新案件

### 步骤1：创建案件数据文件
```bash
# 复制模板
cp src/game/data-orient-express.js src/game/data-new-case.js
```

### 步骤2：修改案件数据
- 修改变量名：`CaseData_orientExpress` → `CaseData_newCase`
- 修改meta信息（id/name/description等）
- 修改scenes/evidence/witnesses/dialogs等游戏数据
- 修改presetLinks（该案件的预设证据关联）
- 修改末尾的`window.CaseData_newCase = ...`和`window.GameData = ...`

### 步骤3：在案件配置中注册
编辑`src/game/cases/index.js`，添加：
```javascript
{
  id: 'new-case',
  name: '新案件名称',
  description: '案件描述...',
  difficulty: '简单/中等/困难',
  estimatedTime: 'XX分钟',
  tags: ['标签1', '标签2'],
  dataFile: '/fun_detective/game/data-new-case.js',
  status: 'available',
  cover: '🔍'
}
```

### 步骤4：同步到public
```bash
cp src/game/data-new-case.js public/game/data-new-case.js
```

### 步骤5：构建验证
```bash
npm run build
```
